# 大问题 4：已实现、未实现、毛盈亏和净损益怎样区分并归因？

## 先看懂：关键词大白话解释

本文适用范围：ETH-USDC-PERP 线性 USDC 永续，数量 ETH、价格 USDC/ETH、乘数 1；单向逐仓、加权平均，费用不入成本，Mark 不改现金。主例无资金费和划转，额外事件均须另行声明。

| 关键词 | 大白话解释 | 在本文里怎么理解 |
|---|---|---|
| 毛已实现交易盈亏 | 只看关闭仓位的交易价差 | 主例累计 480，不自动包含手续费或资金费 |
| 未实现估值 U | 尚未关闭仓位按 Mark 算出的涨跌 | 主例 540，不代表收到五百四十现金 |
| 本笔净现金贡献 | 这笔结转实际给现金带来多少变化 | F3 为 480−3=477，不包含早先已扣的费用 |
| 累计净已结转损益 | 从起点累计入账收益扣累计费用 | 主例为 480−9.3=470.7，与本笔 477 区分 |
| 已平部分净收益 | 为分析平仓表现而分摊开仓费的指标 | 分摊不是再次扣款，也不改变入场成本 |
| 费用归因 | 把费用连回哪笔成交、类型和期间 | 以确定成交费用为准，不以订单预估费重算 |
| 含费成本展示 | 把费用纳入分析读数的另一种表达 | 只能另列派生指标，不能污染本基线 C |
| 生命周期净损益 | 从起点到现在全部交易结果 | 主例 R+U−H=1,010.7，不是权益总额 |
| 期间未实现变化 | 期末估值减期初已存在的估值 | 不能只加期末 U，否则把期初盈利再算一次 |
| 保证金净划入 | 期间转进减转出的本金流动 | 增权益但不属于交易利润，应从权益增量剔除 |
| 平仓归属转移 | 原本账面浮盈转成关闭仓位收益 | 不是在原权益上再奖励完整一份已实现数 |
| 成交价改善 | 实际平仓价相对估值 Mark 的额外差价 | 额外卖 1.2@2,500 对 2,400 的改善是 120 |
| 原始与入账口径 | 十二位经济毛盈亏和六位现金不是同一精度 | 差额由有符号结算余数衔接，清仓也保留 |
| 资金费净额 | 持有合约产生的独立现金收付 | 不改 q、C，不与手续费混扣两次 |

## 把整篇文章压缩成一个故事

小林在乘数一的 ETH 永续里放了一千 USDC，以两千买二 ETH、再以两千三买一 ETH，支付费用四和二点三。加仓后数量三、成本六千三、现金九百九十三点七。现在他选定一个统计期间，期初 Mark 两千二，已有未实现盈利三百、权益一千二百九十三点七。这个期初浮盈必须留在报表边界里，不能等到期末又当成新赚的一笔。

期间内小林只以两千五卖一点二 ETH，费用三。释放成本二千五百二十，毛已实现盈利四百八十，剩余成本三千七百八十。现金本笔增加四百七十七，成为一千四百七十点七；期末 Mark 两千四，未实现盈利五百四十，权益二千零十点七。因此期间净损益是四百八十加上五百四十减三百，再减三，等于七百一十七，恰好等于期末权益减期初权益。

小林问这笔究竟“赚了多少”，系统不能只给一个 profit。减仓本笔净现金贡献四百七十七，从最初累计净已结转却是四百七十点七，因为还要计早先六点三费用；若分析已平部分，按比例分摊开仓费二点五二后，净收益为四百七十四点四八。分摊仅是分析，不能再次扣钱或抬高成本。连同剩余估值的全生命周期净损益则为一千零十点七，权益总额不是利润。

当 Mark 从两千四降至两千三，浮盈从五百四十降至三百六十，权益少一百八十，但现金不变，不能再记一笔现金亏损。未来平仓也只是把对应浮盈转为已实现，实际成交价差与费用才解释权益变化。遇到微小毛盈亏要保留十二位到六位之间的结算余数；资金费和保证金划转另列事件。这样小林才不会把估值当到账、把转入当收益，或因两个“净值”标签而重复扣费。

## 第 1 层：这几个盈亏名称分别代表什么？

**面试官：** 用户问“我这笔交易赚了多少”，你会给他哪个数字？主例 F3 后 Mark 为 2,400 时，毛已实现、未实现、手续费、现金和权益各是多少？

**面试者：** 我会先问清楚要回答的是单笔成交、当前仓位估值，还是账户在某个期间的净损益。它们不是同一个字段。主例 F3 后，累计毛已实现交易盈亏 `R=480`；剩余多仓 1.8、成本 3,780，在 Mark 2,400 下未实现盈亏 `U=1.8×2,400−3,780=540`；累计手续费 `H=4+2.3+3=9.3`。

保证金现金 `B=1,000+480−9.3=1,470.7`。逐仓权益 `E=B+U=2,010.7`。若看从初始至当前的全生命周期、已计交易费用且无资金费和净划入的交易净损益，则是 `R+U−H=1,010.7`；初始现金加它正好等于权益。

这些数字应有明确标签：`R` 是已关闭仓位确认的毛交易盈亏，`U` 是当前 Mark 下尚未实现的估值，`H` 是独立已扣费用，`B` 是已入账现金，`E` 是指定时点的逐仓权益。不能直接把 2,010.7 说成“已赚”，也不能把 540 说成现金到账。

为了让这组口径能适用于多头和空头，还要从统一的方向公式说明已实现和未实现各自如何计算。

## 第 2 层：多头和空头的盈亏公式怎样统一？

**面试官：** 你给的是多头例子。空头的平仓是买入，公式符号容易反。能否用一个带符号的公式同时解释两边？

**面试者：** 可以。方向由 `sign(q)` 表示，`C` 是当前剩余成本，Mark 为 `m`。持有仓位时，`U=sign(q)×(|q|×m−C)`。多头价格高于入场成本得到正 U；空头 `sign(q)=-1`，价格低于入场成本得到正 U。没有持仓，即 `q=0` 时 U 为零。

反向成交关闭旧仓时，关闭量 `c=min(|q|,|d|)`，成本释放 `K` 按加权平均与定点规则计算。毛已实现盈亏为 `g=sign(q)×(c×p−K)`。若 `q>0` 是多仓，卖出高于入场成本得到正收益；若 `q<0` 是空仓，买回低于入场成本也得到正收益。

例如空仓 `q=-3,C=6,300`，买回 1.2@1,900，释放成本 `K=2,520`。毛已实现盈亏 `−1×(2,280−2,520)=240`。Mark 为 2,000 时剩余空仓 1.8 的未实现盈亏是 `−1×(3,600−3,780)=180`。手续费不出现在这些毛盈亏公式里，而作为独立现金效果处理。

若一笔成交过零，只有关闭量 `c` 参与旧仓的已实现公式，新开量建立新成本，不凭新仓数量多算已实现盈亏。公式算对后，还必须防止“已实现”这个词被错误理解为“已经全部扣完费用并入账”。

## 第 3 层：毛已实现盈亏为什么不等于账户已入账净额？

**面试官：** F3 实现毛盈亏 480，费用 3。产品页面把“已实现盈亏”展示成 477 行不行？你会怎样避免毛口径和净口径同时被叫作已实现？

**面试者：** 可以提供净口径，但必须明确命名和组成。持仓内核计算的本笔毛交易盈亏是 480；账本另行扣除本笔手续费 3，所以本笔在忽略其他经济事件时的净现金贡献是 477。若页面把 477 简称为“已实现”，就会让人无法判断费用是已经包含还是还要再减一次。

F3 本笔净现金贡献 477，与从初始到 F3 的累计净已结转损益 `480−9.3=470.7` 不同，后者还扣了此前开仓手续费 6.3。如果报表要计算“已平部分净收益”，必须声明如何分配开仓费；比如按关闭比例 1.2/3 分摊 2.52，则该分析值是 `480−3−2.52=474.48`，不是新扣款，剩余待归因开仓费 3.78 也不进入 `C`。

还要区分内部原始毛盈亏与货币已入账数。内部 `R_raw` 保留十二位；账本转换为六位 USDC 后，可能因舍入余数暂未全部入账。现金增加 477 不等于可提现增加 477，划出仍受保证金、订单预留与风险约束；净口径还必须声明是否包含资金费，不能只靠一个“已实现”标签。

所以接口字段应包含口径名、币种、精度和计算版本；历史展示不能只存一个含义不明的 `profit`。既然费用是单独一项，下一步就要回答每一笔费用依据什么事实归因，怎样避免重复扣除。

## 第 4 层：手续费应如何归因，哪些费用不能混进成本？

**面试官：** 手续费可能随成交类型、费率和折扣变化。是根据订单下单时的预估费率算，还是根据成交价和数量重算？如果要显示开仓成本含费，你会怎么处理？

**面试者：** 本基线规定费用以确定的账户侧成交输入为准，作为独立 USDC 现金支出记录。F1、F2、F3 的费用分别是 4、2.3、3，现金累计支出 9.3；它们不进入入场成本 `C`，也不改变 `A=C/|q|`。

订单时的费用预估可以用于风险准入或用户预览，但最终记账应使用成交结算所确认的费用金额及规则版本。一张订单可能部分成交、成交价不同或经过多次撮合，不能把订单总额当成一笔成交费用随意摊派。费用效果要关联具体账户侧经济事件，便于按成交、市场、费用类型和期间核对。

若产品希望展示“含费成本”或“净收益”，可以提供单独的派生指标，并清楚定义分摊方法；不能把费用先资本化进入 `C`，平仓时经成本释放体现一次，又在现金账本扣一次。那会把同一手续费重复计入净损益。

共同前提下费用非负且是扣款。如果另一产品明确支持返佣，必须把它作为已声明的独立费用反向现金效果及规则变体处理，不能默默把本例的“费用支出”改成可能正负任意的同一字段。之后还要区分按成交生命周期累计的净额和用户选择的查询期间。

## 第 5 层：全生命周期盈亏怎样变成任意期间的损益？

**面试官：** `R+U−H` 是从初始开始的累计口径。用户查询昨天或本月时，能不能用当前累计 R 减去期初累计 R，再加当前 U？

**面试者：** 不能直接这样做，尤其当期初已有未平仓。期间交易净损益要纳入期间发生的毛已实现盈亏、期间费用和资金费，以及期末与期初未实现盈亏的变化。对一个完整风险单元，可表达为：`期间交易净损益 = 期间毛已实现增量 + (期末U−期初U) − 期间费用净支出 + 期间资金费净额`。若毛盈亏原始值与入账值精度不同，还应注明选择哪种口径。

另一个现金权益核对写法是 `期末权益−期初权益−期间净划入`，前提是期初和期末采用同一风险单元与估值口径，所有费用、资金费均已入账，且划入净额定义一致。保证金转入会增加现金和权益，但不是交易利润；转出同理。主例没有划转，因此生命周期权益增量就是 1,010.7。

例如期间从 F2 后开始，明确期初 Mark=2,200，则期初 `U=3×2,200−6,300=300,E=993.7+300=1,293.7`。期内只发生 F3，期末 Mark=2,400，期间净损益为 `480+(540−300)−3=717`，也等于 `2,010.7−1,293.7`。若只加期末 U，会重复计入期初已有的 300，且不能再扣此前费用 6.3。

资金费若纳入“交易净损益”，要带结算期间和唯一经济事件身份，在现金桥接中单列；资金费算法与费率不属于主例。期间与全生命周期口径清楚后，还要理解一次平仓为何会让损益从未实现转到已实现而不必然改变总权益。

## 第 6 层：平仓时已实现增加、未实现减少，权益怎样变化？

**面试官：** 主例当前有 `R=480,U=540`。若再卖出 1.2@2,500，持仓变小，已实现上升、未实现下降。为什么不能把 480 的新增实现盈亏再额外加到原权益上？

**面试者：** 因为在平仓前，关闭部分已经包含在当前未实现估值里。按 Mark 2,400 看，这 1.2 ETH 的旧仓未实现盈亏是 `1.2×(2,400−2,100)=360`。以 2,500 成交后，这部分转成毛已实现 480；其中相对 Mark 多出的 120 是实际成交价格改善，不是凭空新增的 480。

剩余 0.6 ETH 的未实现盈亏是 180。若这笔额外成交手续费为 3，则现金从 1,470.7 增加 `480−3` 到 1,947.7；累计毛已实现从 480 增至 960，累计费用从 9.3 增至 12.3；期末权益为 `1,947.7+180=2,127.7`。相对于之前 2,010.7，增加 117，正是 120 成交价改善减 3 手续费。

这里额外卖出 1.2 是独立分析变体，不叠加总览全平或反向变体；前后都固定 Mark=2,400。另一项只改成交价的独立对照若按 Mark 成交，则新增毛已实现 360、剩余 U=180，计费前权益不变、计费后只减少实际费用。不能把现实手续费默认为零以维持等式。

这说明“已实现”不是额外奖励，“未实现”也不是尚未发生的第二份利润。它们是同一经济损益在仓位是否关闭、按什么价格估值下的不同归属。账本现金只接受已结转的毛交易盈亏和费用，Mark 不直接改现金。

## 第 7 层：舍入余数和资金费怎样进入净损益口径？

**面试官：** 如果毛盈亏只有 0.0000006 USDC，现金还没有达到最小单位，页面和期间报表应该如何显示？资金费又放到哪个公式里？

**面试者：** 本专题固定内部毛交易盈亏保留十二位 USDC，账本现金六位。每笔原始毛盈亏与此前有符号结算余数相加，按向零截断得到六位可入账金额，余下部分继续保留。例如初始余数为零，两次各产生 `0.0000006`：第一次入账零、余数 `0.0000006`；第二次累计达到 `0.0000012`，入账 `0.000001`、余数 `0.0000002`。

因此 `R_raw_u=R_posted_u×10^6+r_u`，左侧为十二位原始毛盈亏，`R_posted_u` 为六位已入账整数。期间也必须保留 `ΔR_raw_USDC=ΔR_posted_USDC+Δr_u/10^12`。账本权益 `E=B+U` 对应已入账口径；高精度经济权益再加 `r_u/10^12`，不能把原始收益桥接到未含余数的 E。负收益同样向零截断并保留负余数，清仓不删除余数。

手续费直接以规则确定的六位现金金额扣除，不与十二位毛盈亏裸相减。现金桥接在本主例下为 `B=B₀+已入账毛交易盈亏−累计手续费`。如果存在资金费或保证金净划入，公式显式扩展为 `B=B₀+已入账毛交易盈亏+资金费净额−手续费净支出+净划入`。

资金费是独立且带结算期间的现金事件，不改 `q,C`。明确变体：主例 F3 后付出资金费 5，则资金费净额为 −5，`B=1,465.7,E=2,005.7`，毛交易盈亏仍为 480。它不叠加其他变体；净已结转损益变为 465.7，不得再把这 5 作为手续费扣第二次。

## 第 8 层：什么样的反例能抓出费用重复和 Mark 污染？

**面试官：** 如果页面显示的总权益与账本余额都大致正确，怎样发现实现中把手续费扣了两次，或者行情更新污染了现金？请用主例给出核对顺序。

**面试者：** 先把每个经济量按其来源独立列出，再验证桥接。主例中 F1 和 F2 后累计费用为 6.3，现金应是 993.7；F3 新增毛盈亏 480、费用 3，现金增量是 +477，期末现金 1,470.7。Mark 2,400 下 U 为 540，权益 2,010.7。费用总计应当只在现金支出中扣一次，而成本仍然是 3,780、均价 2,100。

重复扣费的反例是开仓时先把 F1 费用 4 加进成本，使 `C=4,004`，又从现金扣 4。后续平仓时这额外 4 会通过成本释放影响毛盈亏，导致费用既改变现金又污染毛交易盈亏；若报表再减手续费，净损益再次偏低。正确方案要么按基线把费用完全独立，要么声明另一种费用资本化产品规则，并保证展示与账本不重复扣。

Mark 污染的反例是行情从 2,400 更新到 2,300 后，误把未实现亏损变化 −180 当成现金分录。正确的 `U` 从 540 变为 360、`E` 从 2,010.7 变为 1,830.7；`q=1.8,C=3,780,R=480,H=9.3,B=1,470.7` 全部不变。只有有效成交、费用或其他显式经济事件可以改变相应权威账本状态。

最后按顺序核对账户桥接、仓位成本和估值证据：现金应由已入账经济分录得出，U 应基于同一仓位版本与明确 Mark，权益等于现金加 U；期间损益还应剔除净划入影响并明确资金费。若仅对比一个“总盈亏”字段，已实现与未实现可能相互抵消，无法定位首次错误归因。

## 本题收束

### 已经讲透的机制

- 毛已实现盈亏来自关闭仓位，未实现盈亏是当前仓位按有效 Mark 的估值；两者不是两份利润。
- 手续费独立扣现金；可派生净口径，但必须逐项声明是否已扣费用、是否计入资金费。
- 期间交易损益要纳入期间已实现增量、未实现变化、费用和资金费；权益变化还要剔除净划入。
- 平仓会把一部分损益从未实现转为已实现；实际成交价相对 Mark 的差异与费用才改变桥接结果。
- 原始十二位毛盈亏、六位入账金额和有符号结算余数必须满足精确等式，Mark 更新不改现金。

### 最容易答错的边界

1. 把权益说成已实现利润或可提现现金，把未实现盈亏直接当作账本入账。
2. 只用“已实现盈亏”一个名字，却不说明是毛值、扣费后净值还是还包含资金费。
3. 将费用写入成本后又从现金扣一次，或以订单预估费替代成交结算费用。
4. 用期末 U 代表一个期间的全部损益，忽略期初仓位、期初 Mark 和保证金划转。
5. 清仓时丢弃结算余数，或把 Mark 波动记成现金流水。

### 一个反例与验证

Mark 从 2,400 变为 2,300 后，正确变化是 `U:540→360`、`E:2,010.7→1,830.7`，现金仍为 1,470.7。若现金也减 180，或 F1 手续费既进成本又单独扣账，权益桥接便不再与独立事件归因一致。逐项核对 `R、U、H、B、E` 比较单一总盈亏更能发现错误。
