# 大问题 3：入场成本与均价怎样计算，为什么选择加权平均而不是 FIFO？

## 先看懂：关键词大白话解释

本文适用范围：ETH-USDC-PERP 线性 USDC 永续，ETH 数量、USDC/ETH 价格、乘数 1；单向净仓、逐仓，基线采用加权平均，FIFO 仅为明确切换规则的对照，不是另一种默认口径。

| 关键词 | 大白话解释 | 在本文里怎么理解 |
|---|---|---|
| 绝对入场名义成本 | 剩余敞口入场时对应的价格乘数量 | 多空均保存非负 C，不表示实际支付的本金 |
| 权威 q、C | 真正决定后续成本和损益的原始量 | 展示均价可丢缓存，数量和成本不能用显示值替代 |
| 数量加权 | 买得多的那笔对均价影响更大 | 二 ETH 与一 ETH 不能各算一票简单平均 |
| 比例成本释放 | 按关闭数量占比取走旧成本 | 平一点二／三的仓，释放二千五百二十成本 |
| 入场价与回本价 | 入场基准和策略盈亏平衡指标不是一回事 | 不用已实现收益冲减 C 冒充新入场价 |
| FIFO | 先开的那批仓位先被消耗 | 本例先消耗两千价的旧批次，得到不同实现归属 |
| lot | 保留数量、入场价与先后顺序的一批仓 | FIFO 需要批次明细，平均成本聚合会丢这些信息 |
| 实现时点归属 | 同一总损益被分到已实现还是未实现 | 平均法 480／540 与 FIFO 600／420 不可混称 |
| 合成期初 lot | 切换时用当前总数量总成本建一个新起点 | 能保切换点，不等于还原历史真实批次 |
| 历史重建 | 从完整可信成交重新跑指定成本法 | 只在隔离核验与授权更正下处理差异，不覆盖旧账 |
| 模型生效序号 | 从哪笔开始启用新的成本规则 | 配合规则版本，防止两种算法重复影响同一成交 |
| 成本尾差守恒 | 未分出的十二位成本仍留在剩余仓位 | 每步旧 C 等于释放 K 加新 C，全平释放完 |
| 现金结算余数 | 十二位毛盈亏到六位现金之间暂存的小数 | 独立于成本尾差，不因换成本法或清仓删除 |
| 成本法差分 | 用同一历史比较两种明确模型的逐笔结果 | 总权益相同不足以验证所选规则执行正确 |

## 把整篇文章压缩成一个故事

小林买入 ETH 线性永续：第一笔二 ETH、价格两千，第二笔一 ETH、价格两千三。系统选择的规则是加权平均，因此入场成本四千加二千三等于六千三，数量三，均价两千一。不能把两笔价格简单平均成两千一百五十，因为两笔数量不同；也不能把四和二点三的手续费塞进成本，因为费用已经另扣现金，这不是现货支付本金的过程。

当小林以两千五卖出一点二 ETH，系统按旧仓比例释放二千五百二十成本，确认四百八十毛盈利，留下数量一点八、成本三千七百八十、均价两千一。若拿退出名义额三千直接冲成本，剩余成本会错成三千三，把已经实现的收益又混进未来仓位。部分成本分摊若有微小尾差，留在剩余成本；最终全平释放全部旧成本，过零新仓则按新成交价起步。

小林看到一份 FIFO 对照报告却发现已实现盈利六百，于是怀疑少算钱。原因不是少成交，而是 FIFO 先用掉最早两千价批次中的一点二 ETH，只释放二千四成本，剩余批次成本三千九百。在两千四标记价下，平均法未实现五百四十，FIFO 未实现四百二十，两边毛损益合计都为一千零二十。但两者已实现现金、期间账单与风险输入不同，不能拿总额相同就说规则随便换。

后来产品准备改用 FIFO，小林这段历史不能只靠显示均价复原。用权威数量和成本建合成期初批次，只能保住切换点，不会变出已经聚合丢失的历史顺序。若要声明历史全程 FIFO，必须取得完整成交隔离重放，解释旧账差异并走授权更正，绑定生效序号与规则版本；不能暗改历史分录或承诺自动补发差额。现金结算余数仍要单独继承，估值也始终不是新现金。

**流程位置与核心机制：** 本题位于持仓成本累积与释放阶段，讨论成本代表什么、同向加仓如何形成新均价、减仓如何释放成本，以及加权平均和 FIFO 会怎样改变损益的时间归属。核心权威量是剩余数量 `q` 与成本 `C`，均价是派生结果。

**共同前提：** 沿用[总览中的基线与贯穿案例](README.md#11-讨论基线)：线性 USDC 永续、单向净仓、逐仓、乘数 1、加权平均成本；手续费独立扣现金，`q` 与 `C` 权威，均价不反向重建成本；仓位和账本同一数据库事务。主例无资金费、划转和链上结算。数量与价格六位、内部成本十二位；部分释放 `K` 向下取整、尾数留在仓位，全平时 `K=C`。毛盈亏转六位现金向零截断，余数保留。

本题共 8 层，沿成本定义、迁移、替代规则和迁移边界连续追问：

```text
成本究竟代表什么
    → 同向成交怎样加权
    → 减仓怎样释放成本
    → 为什么加权平均让剩余成本闭合
    → FIFO 会产生什么不同归属
    → 两种成本法能否无损切换
    → 定点尾数怎样留存
    → 如何验证成本模型
```

## 第 1 层：永续仓位里的成本基础到底是什么？

**面试官：** 你说持仓有成本，永续合约没有交割本金。这个成本到底表示什么？它和保证金现金、成交金额以及均价是什么关系？

**面试者：** 在本基线中，`C` 表示当前剩余仓位对应的绝对入场名义成本，是后续关闭仓位时计算毛交易盈亏的基础，不是现金、现货本金或一笔已经付给对手方的货款。多空都保存非负 `C`，方向由 `q` 的符号表达。

非空仓的加权平均入场价是 `A=C/|q|`。它描述剩余仓位的平均入场水平，但不能代替 `q` 与 `C` 成为权威事实。若仓位为空，`A` 不适用，且必须满足 `C=0`。

主例初始保证金现金是 1,000 USDC。F1 买 2@2,000 后，仓位 `q=2,C=4,000,A=2,000`，现金只扣手续费 4，变成 996；不会因为 `C=4,000` 再扣 4,000 名义本金。F2 买 1@2,300 后，`C=6,300,A=2,100`，现金扣除独立手续费 2.3 后为 993.7。

成本法的选择会决定平仓时把多少成本分配给已关闭数量、多少留在剩余仓位，因此也决定已实现与未实现盈亏之间的归属。要理解加权平均，下一步先看两笔不同价格的同向成交怎样形成 `C` 和 `A`。

## 第 2 层：同向加仓为什么不能取两笔价格的简单平均？

**面试官：** F1 的均价是 2,000，F2 又买了 1 ETH@2,300。为什么新均价不是 `(2,000+2,300)/2=2,150`？

**面试者：** 因为两笔成交的数量不同，价格必须按数量加权。对同向成交，新增绝对数量为 `|d|`，新增成本为 `|d|×p`；于是 `C'=C+|d|×p`，`q'=q+d`，派生均价为 `A'=C'/|q'|`。

```text
F1：2 ETH × 2,000 = 4,000 USDC
F2：1 ETH × 2,300 = 2,300 USDC
合计：3 ETH，剩余成本 6,300 USDC
均价：6,300 / 3 = 2,100 USDC/ETH
```

简单算术平均把两笔成交视为各一份，不管第一笔买了 2 ETH、第二笔只买 1 ETH，所以会得到错误结果。若每次只保存并更新展示均价，精度舍入还会在后续加仓中继续累积；保存 `q,C` 再派生均价，计算链条更稳定。

本专题合约乘数为 1，因此数量乘价格就是名义成本。若另一产品每张合约代表 `M` 个标的单位，成本公式要明确乘以 `M`，不能把张数、标的数量和价格单位混为一谈。此处不引入该替代合约参数，仍以基线的 1 为准。

加权平均只定义成本如何聚合，还没有回答减仓时从总成本中取走多少。若减仓重新加权，成交价会污染剩余仓位的入场基准，因此必须规定关闭部分成本的分配方法。

## 第 3 层：部分减仓怎样释放成本而不改剩余均价？

**面试官：** F3 卖出 1.2@2,500 后，成交价比均价高 400。为什么剩余仓位均价仍是 2,100，而不是把 2,500 也平均进剩余数量？

**面试者：** 因为这笔成交中 1.2 ETH 用来关闭旧多仓，它的入场成本按旧仓平均成本同比例释放；成交价只参与计算这部分的毛已实现盈亏。若旧数量是 `|q|`，旧成本是 `C`，关闭量 `c` 小于旧仓，则理想实数表达是 `K=C×c/|q|`，新剩余成本 `C'=C−K`。

主例 F2 后 `q=3,C=6,300,A=2,100`。F3 的关闭量 1.2 对应释放成本 `6,300×1.2/3=2,520`；毛已实现盈亏是 `1.2×2,500−2,520=480`。剩下数量 1.8、成本 3,780，均价仍为 2,100。

若错误地用成交价从成本中扣除 `1.2×2,500`，剩余成本会变为 3,300，均价变成 1,833.33。这等于把已实现收益冲减了剩余仓位的入场成本；以后再平仓会再次从成本差中反映同一收益，混淆“入场成本”和某些产品另行展示的“回本价”。

在无限精度下按比例释放，剩余均价保持不变。在本专题的有限精度规则下，`K` 向下取整到十二位 USDC，微小尾差留在剩余仓位，因此显示均价可能有极小偏差；权威量仍然是剩余 `q,C`。但比例释放还没有覆盖全平和过零，必须先规定旧成本在零点怎样结束，再比较其他成本法。

## 第 4 层：加权平均成本如何闭合全平和重新开仓？

**面试官：** 你的比例释放对部分平仓成立。旧仓恰好全平、超量过零，或全平后重新开仓时，成本如何避免残留或跨仓混用？

**面试者：** 成本迁移需要明确三个边界。部分关闭时只从旧 `C` 释放 `K`，剩余成本是 `C−K`；关闭量刚好等于旧仓时直接令 `K=C`，保证 `q'=C'=0`；成交超过旧仓时旧成本全数释放，剩余量按新成交价建立反向仓成本 `o×p`。

从主例 F3 后的多仓 `q=1.8,C=3,780` 出发，独立全平变体卖出 1.8@2,400：释放全部 3,780，毛交易盈亏 540，仓位成本归零。若独立变体改为卖出 2@2,400，则先关闭旧仓并实现 540，再以 0.2 ETH@2,400 建立空仓，状态为 `q=-0.2,C=480`。

全平后下一笔成交是新仓的成本起点，不把之前已结束仓位的 `C` 接回来。历史毛已实现盈亏、费用和现金流水继续保留在它们所属的累计账务事实中，不属于当前仓位成本。

这是“剩余成本”语义的重要边界。若系统要展示策略批次、税务 lot 或按开仓批次平仓，必须明确引入另一种成本模型；不能一面声称采用单一加权均价，一面又在平仓时暗中选择某个历史成交 lot。

## 第 5 层：换成 FIFO 后，主例的已实现盈亏会怎样不同？

**面试官：** 你说不能暗中选择 lot。那如果产品规定 FIFO，主例 F3 会得到什么结果？它与加权平均是经济上不同，还是只是内部存储形式不同？

**面试者：** FIFO 必须保留每笔开仓 lot 及其剩余数量，平仓时按时间先后消耗最早的 lot。用主例 F1 的 2 ETH@2,000、F2 的 1 ETH@2,300，F3 卖出 1.2@2,500：FIFO 消耗最早 lot 中 1.2 ETH，释放成本 2,400，毛已实现盈亏为 600；剩余 lot 为 0.8@2,000 和 1@2,300，总成本 3,900，剩余均价约 2,166.666667。

加权平均法在相同成交下实现 480，剩余成本 3,780、数量 1.8、均价 2,100。两者最终数量相同，但已实现与未实现之间的时间归属不同。在 Mark 2,400 下，平均法 `R=480,U=540`；FIFO `R=600,U=420`。本例无费用的毛损益合计都为 1,020，但现金、风险输入、期间报表及后续平仓时点的已实现数不同。

如果一个产品按保证金现金和未实现盈亏分别实施限制，或用户按期间查看已实现收入，两种算法的差别不只是内部存储。即便在某个时点总权益相同，交易历史、风险可用量及报表归属也可能不同。产品规则必须选定一种并稳定执行。

FIFO 的适用场景可能包括明确的批次归属需求；加权平均则用较小的状态表示统一净仓，运算更直接。本专题采用加权平均，是既定教学基线，不主张所有交易系统都应选它。下一步必须看两者能否在已有持仓上直接无损切换。

## 第 6 层：从加权平均迁移到 FIFO 能否只按当前均价造一个 lot？

**面试官：** 如果系统已经按加权平均运行多年，迁移时能否用当前 `q,A` 合成一个 FIFO lot？这样能保住数量和成本，为什么还要恢复旧成交？

**面试者：** 这取决于迁移目标。应以权威 `q,C` 建合成期初 lot，而不是用已舍入的展示均价回乘成本。这样能保留切换点数量和成本，但不能恢复真实历史 lot 的先后顺序。因此切换后 FIFO 以合成 lot 为基础，不等同于从历史第一笔起一直执行 FIFO。

若要提供历史 FIFO 归属，需从可信的完整成交序列重放 FIFO，解释与原平均成本账务的差异，不能把历史成交按当前规则直接覆盖。本例会重建成本 3,900、毛盈亏 600，而原值是 3,780、480；涉及既有现金和报表的变化必须经授权更正。只迁移当前聚合状态则应明示期初合成 lot，不宣称恢复了历史 FIFO。

反方向从 FIFO 迁移到加权平均，可以在切换点聚合总剩余数量和总成本，得到新的 `q,C,A`。但原始 lot 明细仍可能需要保留，以支持历史审计、用户报表或回滚核验。聚合之后再切回 FIFO，丢失的信息并不会凭均价自动恢复。

任何切换都应绑定模型规则版本和生效序号，避免同一成交在两个成本法下重复改变账本。模型切换改变的是损益分配规则，不能只当作数据库字段重命名。明确这点后，还要保证聚合成本本身没有被有限精度计算悄悄改写。

## 第 7 层：部分成本释放的舍入尾数应归谁？

**面试官：** 你说部分释放向下取整、尾数留在仓位。如果同一仓位连续减仓多次，最后一次与直接全平的结果会不会不一样？尾数会被清掉吗？

**面试者：** 会有极微小的中间分配差异，因此必须把它作为明示且版本化的舍入规则，而不能假设实数等式在定点整数中仍完全成立。每次部分减仓用当前权威 `C,q` 计算 `K`，按十二位成本向下取整，令 `C'=C−K`；尾数仍属于尚未关闭的仓位。最后一次关闭全部剩余数量时直接释放剩余全部 `C`，不留下幽灵成本。

因此连续减仓时，已释放成本的合计加上当前剩余成本始终等于迁移前成本：每一步都是 `C=K+C'` 的整数等式。不同的拆分方式可能使成本尾差在不同成交之间分配，但最终完全平仓会把剩余成本释放完。相应毛已实现盈亏会依照每次成交实际关闭量与该次成本释放计算，并由相同的规则版本可重放。

本专题还对毛交易盈亏采用独立的现金舍入规则：内部保留十二位，有符号结算余数累积，USDC 六位入账向零截断。这个现金余数不是成本的一部分，清仓不会删除它；也不能把 `C` 的向下取整尾数直接加到现金余数。

展示均价可按接口精度格式化，但不能把显示值乘回数量写成新 `C`。例如 `C/|q|` 的小数显示为有限位后，回乘往往不等于原始十二位成本。持仓版本应保存数量、成本和模型版本；均价缓存失效后可安全重算。

## 第 8 层：怎样验证成本法与收益归属的关系？

**面试官：** 如果加权平均和 FIFO 在 Mark 下总权益相同，是否足以证明任一实现正确？你会怎么构造验证，特别是确保没有把手续费或未来成交混入成本？

**面试者：** 不足以。总权益相同可能只是已实现与未实现的差额相互抵消，不能证明成本归属符合选定规则。应逐事件核对数量、剩余成本、成本释放、毛已实现盈亏和现金；并明确比较对象采用相同成交序列、Mark、手续费和费用口径。

对基线加权平均，主例手算向量为：F1 后 `q=2,C=4,000,A=2,000`；F2 后 `q=3,C=6,300,A=2,100`；F3 后 `q=1.8,C=3,780,A=2,100`，本笔释放成本 2,520、毛已实现盈亏 480。检查成本守恒、同向加仓按数量加权、减仓不按退出价改成本、全平 `C=0`、反向新仓按本笔价格建立成本。

再用同一历史在独立的 FIFO 规则参考模型中验证预期 600 已实现、3,900 剩余成本。若业务选的是加权平均，却得到 FIFO 的数字，或反之，模型规则就被错误替换。Mark 变化只能改变未实现值，不能改写 `q,C`、历史毛已实现盈亏或现金。费用要单独核对，不能因成本模型不同就被混入 `C`。

最有力的反例是 F3 前再多开一笔不同价格的 lot，随后只关闭一小部分：FIFO 会明确消耗最早 lot，而加权平均按聚合比例释放；若实现只比较最终数量或权益，就可能漏掉归属错误。还要覆盖全平、过零、微小尾差和成本模型切换边界，验证结果与声明的规则完全一致。

## 本题收束

### 已经讲透的机制

- 入场成本是当前持仓的名义成本基础，不是永续本金、保证金现金或费用；权威量是 `q,C`。
- 加权平均同向加仓按数量聚合成本；部分减仓按关闭比例释放旧成本，成交价用于毛盈亏而不重新定价剩余仓位。
- 全平释放全部剩余成本；过零后新方向按新成交价建立成本；历史损益和费用不随空仓清零。
- FIFO 需要保存并按序消费 lot，与加权平均可能在同一成交下产生不同的实现时点和报表归属。
- 成本法切换要声明切换点、规则版本和历史重建能力；定点尾差留在剩余成本，和现金结算余数分开。

### 最容易答错的边界

1. 对不同数量成交取价格简单平均，或把显示均价当权威成本。
2. 用平仓成交价冲减剩余成本，导致已实现收益被再次揉进未来盈亏。
3. 认为 FIFO 只是数据结构差异，忽略期间实现损益和风险归属会改变。
4. 用一个合成 lot 迁移后声称完整重建了历史 FIFO。
5. 把成本尾差当手续费、现金余数，或清仓时把账务尾数一并抹掉。

### 一个反例与验证

主例 F1、F2 后卖出 1.2@2,500：加权平均应实现 480、留成本 3,780；FIFO 应实现 600、留成本 3,900。数量都为 1.8，Mark 2,400 下毛总损益都为 1,020，但归属不同。逐项核对成本、已实现盈亏和剩余均价，才能证明实现遵守了选定的成本法。
