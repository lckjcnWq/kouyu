## 先看懂：关键词大白话解释

本文适用范围：ETH-USDC-PERP 线性永续，ETH 数量、USDC/ETH 价格、乘数 1；单向净仓而非多空双向仓，逐仓、加权平均成本、费用单扣。数量价格六位，内部成本毛盈亏十二位，现金六位。

| 关键词 | 大白话解释 | 在本文里怎么理解 |
|---|---|---|
| 有符号净数量 q | 用正负数同时表示方向和规模 | 多三记 +3，空三记 −3，零没有方向敞口 |
| 剩余成本 C | 还没关闭的仓位携带的入场依据 | 始终非负，不是保证金或已支付货款 |
| 同号成交 | 成交方向和旧仓方向一致 | 只增加数量及成本，不产生平仓毛盈亏 |
| 异号成交 | 成交朝旧仓相反方向走 | 先减旧仓，不能把每次卖出都当新开空 |
| 关闭量 c | 本笔真正用来消掉旧仓的数量 | 取旧仓与成交绝对量中较小的一个 |
| 新开量 o | 平旧仓后还有多少成交未用完 | 仅超过旧仓的部分建立反方向仓位 |
| 成本释放 K | 随关闭量退出的旧入场成本 | 部分按比例，全平直接取全部旧成本 |
| 本笔毛盈亏 g | 关闭旧仓得到的价差结果 | 不含手续费，也不等于本笔现金净变化 |
| 空仓不变量 | 没仓位就不能遗留当前成本 | q 为零时 C 必为零，均价不适用 |
| 过零反向 | 一笔成交把净数量从正变负或反过来 | 新仓成本按本笔成交价，不继承旧均价 |
| Reduce-Only | 只准减已有仓位的执行资格 | 应在成交前限制，结转不能事后裁掉超额成交 |
| 成本尾数 | 比例分摊未分出去的微小成本 | 留给剩余仓位，全平时一次释放干净 |
| 结算余数 | 原始毛盈亏暂不足最小现金单位的部分 | 清仓不删除，和成本尾数分开保存 |
| 多空对称验证 | 把旧仓方向和价格方向反过来检查 | 买入平空也沿用同一关闭公式，不另造收益方向 |

## 把整篇文章压缩成一个故事

小林交易的不是现货，而是乘数一的 ETH 线性永续。他放入一千 USDC 后，先以两千买二 ETH，再以两千三买一 ETH，得到有符号数量正三、成本六千三、均价两千一；两笔费用共六点三，现金九百九十三点七。“买入”这次是开多加多，但若旧仓本来为负数，同样的买入首先就是平空，方向必须连着旧状态一起看。

随后他以两千五卖一点二 ETH，成交数量记负一点二。内核把关闭量定为一点二，新开量为零，释放旧成本二千五百二十，得到毛盈利四百八十。剩余数量一点八、成本三千七百八十，均价仍为两千一，而不是把卖出价再混进均价。扣本笔三 USDC 费用后，现金一千四百七十点七；名义卖出额三千不能当作收到现货货款。

接下来小林提交并获准成交一笔两 ETH、价格两千四的卖出。系统先用一点八 ETH 平尽旧多仓，释放全部三千七百八十成本，实现五百四十，再把多出的零点二 ETH 建成空仓。新数量负零点二、成本四百八十、均价两千四。累计毛盈利一千零二十，累计费用十四点一，现金二千零五点九。不能对整笔两 ETH 都结旧仓收益，也不能让新空仓继承旧均价。

若标记价随后降到两千三，新空仓只是多出二十 USDC 未实现盈利，现金与已实现数不变。若原订单仅准减仓，超额资格应在撮合前拦住，不能成交后偷偷抹掉零点二。定点计算部分释放向下取整，现金转换向零截断，各自留存尾数；以后仓位归零，只清数量和当前成本，不清历史费用、盈利或结算余数，更不能据此承诺全部现金都可划走。

**流程位置与核心机制：** 本题位于确定成交进入持仓折叠之后，聚焦一笔有符号成交怎样把旧净仓迁移为新净仓。核心是先区分关闭旧仓与新开反向仓，再依据两者关系处理数量、成本和毛已实现盈亏；订单资格与经济状态迁移各有边界。

**共同前提：** 沿用[总览中的基线与贯穿案例](README.md#11-讨论基线)：线性 USDC 永续、单向净仓、逐仓、乘数 1、加权平均成本，手续费独立扣 USDC；`q` 与 `C` 权威，均价由两者派生；持仓和账本同一数据库事务。成交量 `d` 有符号，买入为正、卖出为负。主例资金费为零，Mark 不改现金。部分成本释放向下取整、尾数留在仓位；全平直接释放全部 `C`。毛盈亏转六位现金向零截断，余数保留。

本题共 8 层，沿同一条状态迁移主线追问：

```text
用什么状态表示净仓
    → 如何区分同向和反向成交
    → 反向成交怎样拆成关仓与开仓
    → 恰好全平怎样消除旧状态
    → 过零后的新方向怎样定价
    → 订单资格为何不由持仓内核补救
    → 精度和顺序怎样约束迁移
    → 用哪些反例证明模型闭合
```

## 第 1 层：单向净持仓最少需要保存哪些权威状态？

**面试官：** 如果一个账户在同一合约只允许单向净持仓，你会用哪些字段表达仓位？为什么不能只保存方向、数量和均价？

**面试者：** 我会把仓位的权威经济状态收敛到有符号数量 `q` 和非负剩余成本 `C`，并保存版本与规则版本用于解释其来源。正 `q` 是多仓，负 `q` 是空仓，零是空仓。均价 `A=C/|q|` 只在非空仓有定义，是派生视图，不是第二份可独立修改的事实。

这样设计的原因是一次成交改变的不是单独一个展示字段，而是数量、剩余入场成本和可能发生的毛已实现盈亏。若只保存均价，部分减仓后会遇到精度舍入；把四舍五入均价乘回剩余量，可能不能还原原成本。若方向与数量分开，方向和数量还可能短暂不一致。一个带符号数量表达净方向，成本保留足够精度，规则更容易检查。

主例从 `q=0,C=0` 开始。F1 买入 2 ETH@2,000 后，仓位为 `q=2,C=4,000`；F2 再买 1 ETH@2,300 后，状态为 `q=3,C=6,300`，展示均价 2,100。累计毛已实现盈亏和手续费属于相邻的经济账务状态，不用塞进成本字段里。

| 状态含义 | 权威或派生量 | 不能混用的量 |
|---|---|---|
| 当前净方向及规模 | 有符号 `q` | 订单原始委托量、未成交量 |
| 剩余入场成本 | 非负 `C` | 保证金现金、已支付货款 |
| 入场均价 | 派生 `A=C/|q|` | 四舍五入展示价不能回写成本 |
| 迁移产出的收益 | 本笔原始毛盈亏 `g` | 不包含手续费，不等于现金净增量 |

F1 后现金为 996，F2 后为 993.7。成本 4,000 或 6,300 不扣名义本金；保证金要求约束交易资格，也不是在同一现金桶里再扣一笔成本。这个区分能防止状态机从起点就按现货记账。

约束空仓不变量：`q=0` 时 `C=0`，均价不适用。清仓后历史盈亏和费用仍存在于累计结果和账本中，但旧仓的方向与入场成本不能残留。这个状态模型能表达开仓、加仓、减仓和反向，不过还要说明如何从成交方向判断每种情况。

## 第 2 层：怎样用同一规则区分同向加仓和反向成交？

**面试官：** 你说 `q` 带方向。一笔买入到底是开多、加多还是平空？如果只看“买入”这个动作，分类会不会有歧义？

**面试者：** 会有歧义，所以我不会把买入直接映射成开多，也不会把卖出直接映射成开空。先看旧仓 `q` 与成交量 `d` 的符号：空仓或同向成交属于新开方向的持仓量；只有旧仓非空且方向相反，才需要关闭旧仓。

```text
q = 0：成交建立新仓，数量 q' = d
q 与 d 同号：同向加仓，数量 q' = q + d
q 与 d 异号：先关闭旧仓，超出部分才可能建立反向新仓
```

例如 `q=3` 时买入 `d=+1` 是多仓加到 4；卖出 `d=-1.2` 才是减多。若 `q=-3`，买入 `d=+1.2` 是买入平空；卖出 `d=-1` 则是空仓加到 −4。方向由旧仓状态与本笔成交方向共同决定。

同向加仓时没有关闭旧仓，因此本笔毛已实现交易盈亏为零，新增成本是成交数量绝对值乘成交价。开仓和加仓的手续费仍按成交规则单独扣现金，不能因为毛已实现盈亏为零就说本笔对余额没有影响。

这个分类也解释了为什么成交价不能决定仓位方向：买入价高于旧均价并不会自动把多仓变成空仓，卖出价低于均价也不会自动改变持仓方向。方向只由数量守恒决定；价格影响成本和盈亏。下一步需要把异号成交拆成可计算的两部分，而不是写多套长短仓分支。

## 第 3 层：反向成交怎样分解成关闭量和新开量？

**面试官：** 对异号成交，你说先关旧仓。关闭多少、剩下多少由什么决定？请用 F3 推导，而不是只给一句 `min`。

**面试者：** 设旧仓数量为 `q`，本笔有符号成交为 `d`，方向相反时，关闭量是 `c=min(|q|,|d|)`，反向新开量是 `o=|d|-c`。因此 `c+o=|d|`，整笔成交数量既不会漏掉，也不会被重复使用。

主例 F2 后是 `q=3,C=6,300`。F3 卖出 1.2，所以 `d=-1.2`，旧仓为多，`c=1.2`、`o=0`。该成交全部用于减少旧多仓，没有新开空仓。按加权平均成本释放 `K=6,300×1.2/3=2,520`，毛已实现盈亏为 `1.2×2,500−2,520=480`；新状态是 `q=1.8,C=3,780`。

空仓方向仍然复用公式，只是符号反转。例如 `q=-3,C=6,300`，买入平仓 1.2@1,900，`c=1.2,o=0,K=2,520`。毛已实现盈亏为 `sign(q)×(c×p−K)=−1×(2,280−2,520)=240`。空头低价买回，得到正收益，不需要再发明另一套公式。

关闭量只对应旧仓的一部分或全部，因此只释放旧成本；新开量若非零，则按本笔价格建立独立的新方向成本。这个分界是后续计算的关键：减仓成交价不能混进仍存续的旧仓成本，过零后的反向部分也不能沿用旧均价。

## 第 4 层：恰好全平时成本和历史损益分别怎样处理？

**面试官：** 当成交绝对量正好等于旧仓时，按比例释放成本可能有小数尾差。你会让剩余成本留一点，还是按新数量归零处理？历史实现盈亏会不会也清空？

**面试者：** 恰好全平时必须识别 `c=|q|`，直接取 `K=C`，而不是再通过近似比例计算。更新后 `q'=0,C'=0`。这保证空仓状态成立，不会出现数量已平但仍显示非零成本、均价无定义却留下幽灵持仓的情况。

沿用总览的独立全平变体：从 F3 后 `q=1.8,C=3,780,B=1,470.7` 出发，卖出 1.8@2,400、费用 4.32，直接释放全部成本 3,780，新增毛盈亏 540，得到 `q=0,C=0`。累计毛盈亏为 1,020，累计费用为 13.62，现金为 `1,000+1,020−13.62=2,006.38`。

全平只清理当前仓位数量和入场成本，不清累计毛已实现盈亏、历史手续费、账本记录或结算余数。若下一笔再买入 1@2,600，那是新开多仓，状态为 `q=1,C=2,600`，新均价 2,600，而不是把旧仓历史成本重新平均进去。

全平直接释放全部旧成本是本专题声明的定点规则；不足一个最小 USDC 单位的毛盈亏则由独立的有符号结算余数处理。两种尾数不是一回事：成本尾数决定剩余仓位的成本基础，现金结算余数决定多少原始毛盈亏已达到货币最小单位。不能因为仓位归零就删掉后者。

## 第 5 层：一笔成交大于旧仓时，反向新仓的成本如何建立？

**面试官：** 如果卖出量超过旧多仓，不只是全平。如何避免把整笔卖出都按旧均价结算，或把新空仓的入场价错误地设成旧均价？

**面试者：** 当 `o>0`，表示旧仓已经全部关闭，成交剩余部分在反方向新开仓。旧仓的毛盈亏只使用关闭量 `c` 和旧成本释放 `K`；新仓成本只使用新开量 `o` 与本笔成交价 `p`。两段虽然来自一笔成交，经济含义不同。

从主例 F3 后的状态 `q=1.8,C=3,780` 出发，独立过零变体为卖出 2@2,400、费用 4.8，不叠加上一层的全平变体。关闭 `c=1.8`、释放成本 3,780、实现毛盈亏 540；剩余 `o=0.2` 建立空仓，`q'=-0.2,C'=480,A'=2,400`。累计毛盈亏 1,020、费用 14.1，现金为 2,005.9。

若把 2 ETH 全部乘以 2,400 再减掉旧成本，会把新开空仓的名义数量误当作旧仓平仓量；若把新空仓成本设成 `0.2×2,100`，又把旧仓的加权均价带过了零点。正确结果必须同时满足数量守恒和成本分段：`q'=q+d=-0.2`，`C'` 只对应剩下新开的 0.2 ETH。

同价 Mark 2,400 下，新空仓未实现盈亏为零。若 Mark 变成 2,300，则该空仓的未实现盈亏为 `−1×(0.2×2,300−480)=20`。Mark 的变化只改变估值，不改这个新仓的数量、成本或已经实现的 540。

## 第 6 层：Reduce-Only 和成交资格由谁保证？

**面试官：** 过零会扩大反方向风险。假设订单标记为 Reduce-Only，实际到账成交量却大于可平数量，持仓内核能否把超出的部分截掉，避免开出新方向？

**面试者：** 不能。订单执行侧负责判断成交资格和可成交数量，持仓内核负责忠实折叠已经确定的账户侧成交。若上游提交了权威的 2 ETH 卖出成交，结转服务不能只应用 1.8、悄悄丢掉 0.2；那会让成交义务、对手方结果和账户仓位互相矛盾。

Reduce-Only 的约束应在订单接入、撮合裁决及执行过程中生效。订单剩余量可能随着其他成交、撤单和状态变化而变化，执行方必须在决定成交前校验当前资格。部分成交后撤掉剩余订单，不会撤销已确定的成交。过零是否允许，是订单与风险规则的结果，不是计算内核根据仓位大小临时决定的业务许可。

持仓内核仍需要验证输入结构：成交量非零、方向与账户事件载荷一致、所属风险单元正确、精度与规则版本可识别。输入非法或身份载荷冲突时应停止并报告；但不能用“仓位太小”作为理由，丢弃一笔已经确定且有效的成交。

如果有明确证据表明上游对 Reduce-Only 裁决错误，处理方式是隔离该异常、保留原始成交、触发对账和经授权的纠正流程。直接裁剪数量会制造无法审计的隐式改单。这一责任边界明确后，还要回答定点精度下公式怎样保持不变量。

## 第 7 层：有限精度下如何保证数量和成本仍然闭合？

**面试官：** 你的公式用了比例 `C×c/|q|`。实际数量与价格是六位精度、成本是十二位精度时，重复减仓可能产生尾数。哪些量取整，取整后不变量是什么？

**面试者：** 按总览规则，数量 `q`、成交量 `d`、成交价 `p` 用六位定点，成本 `C` 和毛交易盈亏内部用十二位 USDC 定点。反向成交的部分关闭量按 `K=floor(C×c/|q|)` 向下取整，差额留在剩余仓位成本里；若 `c=|q|`，则直接 `K=C`。乘法和除法中间值要有经过推导的足够位宽。

部分减仓后设置 `C'=C−K`；只要仍有旧仓，就不重新按成交价给剩余仓位加权。过零时旧仓全部关闭，`C'` 改为 `o×p`；恰好全平则为零。任何路径都要求成本非负，并且 `q'=0` 时当前仓位成本必须为零。

由于比例计算的向下取整，剩余仓位的派生均价可能出现非常小的尾差；权威状态仍是 `q` 与 `C`，不能为了让 UI 显示好看而覆盖成本。毛交易盈亏以十二位精度计算后，按有符号余数规则转换成六位 USDC 入账金额；这一步的向零截断不应与成本释放规则混为一谈。

连续迁移还必须使用同一事件顺序和同一规则版本。成本释放具有前态依赖；若并发地用同一个旧状态计算两笔卖出，两个结果分别合法但合起来会超额减仓。串行化当前风险单元的迁移是状态计算前提，持仓和账本最终仍按共同事务提交。

## 第 8 层：怎样用反例检验状态迁移没有漏算？

**面试官：** 如果最终数量正确，你怎样知道分支逻辑没有把部分减仓、全平和过零混在一起？请给出有区分度的验证办法，并总结最危险的错误。

**面试者：** 我会围绕边界量验证，而不是只测一笔普通减仓。固定旧仓 `q=3,C=6,300`，分别输入反向成交量 1.2、3 和 3.2，成交价都取 2,500。预期依次为：保留多仓 1.8、毛盈亏 480；空仓、成本归零、毛盈亏 1,200；以及新空仓 0.2、成本按 0.2×成交价建立、旧仓毛盈亏仍为 1,200。这样能区分 `|d|<|q|`、相等与大于三种边界。

每个案例都核对数量守恒 `q'=q+d`、关闭量和新开量分解、成本非负、空仓成本为零、全平释放全部 `C`。多空对称案例应在对应价格方向下产生正确符号；Mark 单独变化时，仓位数量、成本、已实现毛盈亏和现金保持不变，只重算未实现盈亏。

一个直接反例是把“卖出”永远解释成开空：F3 后就会错误地在仍有 3 ETH 多仓时增加空仓，而不是减至 1.8。另一个反例是无论成交量大小都按整笔释放旧成本：部分减仓会提前耗尽全部旧成本；过零后若不另建新成本，则会留下非零新仓却成本为零。再一个反例是先把均价或关闭比例舍入，再回算全平释放成本，可能留下 `q=0,C>0`；若采用足够位宽的整数先乘后除，全平时 `c=|q|`，比例公式本身会精确得到全部 C，不会留下残余。

面试中我会明确模型适用条件：这是线性合约、单向净仓、加权平均成本。双向持仓需要分别维护多空状态，反向合约要改变盈亏公式，全仓共享现金会改变账户风险边界；这些都是改变前提后的独立设计，不能把本题公式不加说明地套用过去。

## 本题收束

### 已经讲透的机制

- 用有符号 `q` 表示净方向，用非负 `C` 表示剩余成本，均价只派生。
- 同向成交只增加同方向数量与成本；反向成交拆成关闭旧仓的 `c` 和新开反向仓的 `o`。
- 部分减仓只释放旧成本；全平直接释放全部成本并令 `q=C=0`；过零后新仓按成交价建立成本。
- 成交资格由订单执行侧裁决，结转不能私自裁剪权威成交；Mark 只改变估值。
- 定点规则明确区分成本尾数和毛盈亏结算余数，迁移需要连续且确定的前态与规则。

### 最容易答错的边界

1. 把买入一律当开多、卖出一律当开空，不看旧仓方向。
2. 部分减仓时用成交价重算剩余均价，或把整笔过零成交都按旧仓结算。
3. 全平只把数量置零，却保留成本；或误把历史损益、费用一并清零。
4. 结转服务擅自裁剪 Reduce-Only 的已确定成交量。
5. 把成本释放的向下取整和现金结算的向零截断混为同一舍入规则。

### 一个反例与验证

从 `q=1.8,C=3,780` 出发，卖出 2@2,400。若结果不是先关闭 1.8 并实现 540，再以 0.2@2,400 建立空仓成本 480，状态迁移就把旧仓与新仓混在一起了。再验证相等量全平时 `q=C=0`，Mark 更新不改现金和历史已实现值，即可覆盖最关键的边界。
