# 大问题 12：为什么有的协议用累计资金费指数，链上又改变什么？

<!-- 大白话导读开始 -->

## 先看懂：关键词大白话解释

| 关键词 | 大白话解释 | 在本文里怎么理解 |
|---|---|---|
| 资金费／手续费／借款利息 | 资金费通过持仓双方的周期或累计收付影响持仓激励，不是成交服务费或借贷计息。 | 改成指数或搬到链上，不改变费用必须有归属和真实资金承接的要求。 |
| q、M、f／收付符号 | q 是带符号数量，M 是参考价，f 是对应计费段费率。 | 本文多正空负、应付为正时现金减少，所以正费率多付空收，负费率反向。 |
| 周期快照／连续累积 | 前者按一个截止位置的仓位归属整周期，后者按各持仓段承担相应增量。 | 连续例明确更改规则，不能把按需记账自动解释为按持有时长收费。 |
| 累计资金费指数 K | 把每单位仓位历次应付累加起来的一本市场总刻度。 | 单位 USDC/ETH，不是行情中的指数价格，也不是用户账上的费用累计字段。 |
| ΔK／M_k×f_k | Δ 表示变化量；某段参考价乘费率形成该段每单位仓位的应付增量。 | K 按规则加增量，不能每小时都加一遍完整八小时费率。 |
| K_now／K_checkpoint | 前者是当前市场刻度，后者是该仓位段已经结到的刻度。 | 二者之差是尚未结转的单位费用，不由“今天几点记账”决定资格。 |
| D／ΔB | D=q×(K_now-K_checkpoint) 是未结有符号应付，ΔB=-D 是现金变化。 | 例如旧多仓 1 ETH 遇到指数增量 0.05，应付 0.05 USDC。 |
| 惰性结算／按需结转 | 市场先维护刻度，账户在必要操作时再落实自己的费用。 | 只是减少逐户更新；若 K 仅周期跳变，仍须由原屏障仓位承接该义务。 |
| 固定小时费率／连续例 | 连续例预先公布每小时 0.0001/8，并规定不足一小时的累积办法。 | 价为 2,000 时每小时增 0.025 USDC/ETH，八小时增 0.2，不是提前使用未定最终费率。 |
| 旧仓先结／新仓后改 | 改数量前先用旧数量结清截至当前刻度的费用，再推进检查点。 | 防止新买数量背上旧费用；空仓重开也先更新检查点，空仓段不计费。 |
| 平仓／欠款身份 | 平仓把数量归零，欠款身份保存已确定但未付清的历史义务。 | 零仓只停止后续按该仓计费，不删除旧费用、债权或审计记录。 |
| 未实现盈亏 U／净权益 E | 未实现盈亏是尚未平仓的价格盈亏，净权益还需扣掉未结义务。 | 连续例可写 E=现金+未实现盈亏-D；负 D 的应收是否足额计入须按可收回规则。 |
| 风险读取／版本复核 | 提款等操作要按同一顺序读取有效指数和最新账户状态。 | 陈旧 K 不能放行资金外流；周期快照已封存时还要识别冻结计划应付。 |
| 固定点／账户级高精度余数 | 固定整数精度计算，保留分段结算时不足现金最小单位的部分。 | 连续模型需明确余数归属，不照搬前文快照基线“不跨周期累计尾数”的规则。 |
| 清算账户／应收应付 | 显式承接不同账户尚未同时落账的资金义务。 | 惰性结算阶段现金流水不一定零和，未结责任不是可以随手塞进尾差的小数。 |
| 舍入尾差／Σq=0 | 尾差只平衡量化残差；Σq=0 表示全市场数量相抵。 | 最终用户、清算科目和舍入项要闭合，不能借尾差掩盖缺仓或造钱。 |
| 授权缓冲／负现金 | 缓冲是可控制的真实承接能力，负现金表示欠款而不是实收。 | 不足额不能自动视为已足额清偿；无承接能力按规则暂停，收款也不自动可提现。 |
| 链上权威／链下权威 | 必须先说清谁保存最终有效的仓位、指数、检查点和账务。 | 只把 USDC 转上链，不会自动证明链下仓位和费用算得对。 |
| 费率发布者／keeper | 发布者获授权更新费率或指数，keeper 是按权限推动合约动作的执行者。 | 检查序号、规则版本与陈旧度，暂停和升级权限也要受约束。 |
| EVM／同一交易原子性 | EVM 是执行合约的虚拟机；同笔交易中的状态可共同回滚。 | 同链调用的原子范围不能直接延伸到跨链桥或异步提款。 |
| tx 提交／上链执行／最终性 | 提交只说明广播交易，上链表示进入当前链并执行，最终性按目标链规则确认稳定性。 | 三者不能画等号；上链成功也不证明足额到账或欠款已清。 |
| 交易哈希／事件序号／区块哈希 | 分别定位交易、交易内事件及其所在区块。 | 消费者用它们识别事件和链分支，同时保留业务效果稳定身份防重。 |
| 链重组／索引器／规范链 | 重组可能撤销先前区块，索引器整理链上事件，规范链是最终采用的有效链历史。 | 撤回失效投影、重放规范事件，并按仓位、指数、欠款和实际到账逐项核对。 |

## 把整篇文章压缩成一个故事

1. 原方案在屏障按仓位归属整周期资金费；这不是手续费或借款利息。按本文多正空负、正费率多付空收的约定，参考价 2,000、八小时费率 0.0001，每 ETH 应付 0.2 USDC。费率冻结、资格确定和资金入账是不同步骤，后来平仓不抹旧义务。

2. 本题另设连续规则：提前约定小时费率 0.0001/8，单位费用刻度 K 每小时增 0.025。多仓 1 ETH 持有前两小时后平仓，付 0.05；原快照规则若屏障前平仓则付零。改仓前先按旧数量乘指数差入账，再推进检查点，不能让新仓背旧费。K 不是价格指数，暂未结转责任也不是舍入尾差。

3. 搬上链还要说明谁权威保存仓位、谁能更新指数。广播 tx、上链执行、满足最终性规则并非一回事；成功回执也不证明足额到账。重组要撤回失效投影并重放，再核对实收与债权。欠款需要真实承接，零仓不消债，结转不改成交价，纠错也不能抹历史。

**必要前提与相邻题边界：** 总览基线是链下托管、ETH-USDC 线性永续，乘数 1，正费率多付空收，并按 08:00 屏障仓位对整个周期做时点快照。本题比较另一种明确改规则的方案：市场级累计指数 `K`，单位 `USDC/ETH`。它承接第 03 题的结算资格、第 04/05 题的金额精度与账本、第 07/08 题的顺序和风险约束，但不重讲费率采样，也不把链上转账当作仓位或账本的权威来源。总览里的“资金费累计”账务字段不等于这里的价格化指数 `K`。

## 第 1 层：累计指数替换了什么？

**面试官：** 有的协议不逐周期遍历所有账户，而是维护累计资金费指数。它解决什么问题，又改变了总览的什么规则？

**面试者：** 先给结论：累计指数把逐户批量计算改成按需结转，降低更新全部账户的开销；上链则改变状态权威、执行权限、原子提交范围与最终性，不自动免除坏账。维护市场级 `K`，每次按 `K += M_k*f_k` 更新，`K` 和增量单位都是 `USDC/ETH`；账户按 `ΔB=-q*(K_now-K_checkpoint)` 改变现金，`q` 以 ETH 计、乘数为 1。检查点代表该仓位段已结到哪个指数，不能用记账时间决定付费资格。总览在 08:00 按屏障仓位收整周期费；本题后续连续模型明确改为按时间累积，让窗口内仓位分别承担对应增量，但指数本身也可仅作周期快照义务的惰性实现。两种规则不能因公式相似而混用。

## 第 2 层：指数跳变频率怎样改变经济结果？

**面试官：** 你说连续累积改变了资格，给一个沿用总览数值、又不会把周期费率重复计算的例子。

**面试者：** 可以，但先改变费率生效规则：事先公布固定每小时费率 `f_k=0.0001/8`，八小时内参考价保持 `2,000 USDC/ETH`，不是提前使用总览在窗口结束后才确定的最终费率。连续规则规定任意时长 `Δt` 的 `ΔK=0.025×(Δt/1小时) USDC/ETH`，不足一小时也按此累积；完整八小时仍累计 `0.2 USDC/ETH`，不能每小时重复收完整周期费。持有 1 ETH 前两小时后平仓，连续方案付 `0.05 USDC`，总览快照方案付零；若只在屏障前开仓并跨过屏障，总览仍收完整 `0.2 USDC`。反过来，若 `K` 仅在结算时跳变，它只是周期义务的惰性实现：必须让屏障仓位承接该增量，按权威顺序先推进到期指数，再处理屏障后的改仓；延迟落账不改变资格。指数公式相同不代表经济规则相同。

## 第 3 层：仓位变化时怎样避免新仓继承旧费用？

**面试官：** 连续方案中，账户加仓、减仓或反手时，检查点和仓位应按什么顺序更新？

**面试者：** 对同一风险单元先锁定当前仓位版本，读出旧数量 `q_old`、旧检查点 `K_checkpoint` 和当前 `K_now`，先计算并入账 `-q_old*(K_now-K_checkpoint)`，再把检查点推进到 `K_now`，最后才应用成交改变数量。比如原有多仓 1 ETH，指数已增加 `0.05 USDC/ETH`，此时再加 1 ETH，先结旧仓的 `0.05 USDC`，再把仓位改为 2 ETH；新买入的 1 ETH 不会追缴过去两小时的费用。减仓与反手同理，旧方向先结清，再以新数量从当前 `K` 开始。空仓重开也先把检查点推进到当前指数，空仓期间不计费。指数更新与改仓必须共用可恢复的权威顺序。资金变化、数量、检查点和成交身份必须在同一权威提交域按确定顺序生效，否则重试或并发成交可能漏收、重复扣款或把旧增量套到新仓。

## 第 4 层：清仓后欠款和检查点如何保留？

**面试官：** 如果平仓结转后现金不足，即使仓位变成零，是否可以把检查点和资金费状态一起清掉？

**面试者：** 不可以。先按旧仓结算资金费，并将平仓盈亏和其他费用一并评估；最终现金不足时，有授权承接能力才允许记负现金并形成欠款，否则暂停对应结转或按明确的风险处置规则收敛，不能抹掉义务。清仓只终止后续按该仓计费，不消灭历史债权；收款方的账面应收也不自动可提现。成功结转时检查点推进到当前指数，欠款保留独立稳定身份，追偿只冲减欠款，不能重复扣旧费用。重开仓前再把检查点推进到届时指数，空仓期间没有资金费。若指数仅周期跳变，历史资格仍由冻结屏障决定，不能用清仓后的零仓重写；若整笔操作回滚，现金、检查点和仓位都不得半途生效。

## 第 5 层：风险读取怎样防止未入账义务被提款逃掉？

**面试官：** 资金费可能已经累计但尚未写入用户现金。风险计算和提款校验怎样处理这段窗口？

**面试者：** 风险不能只看账面现金。对连续指数，未结金额可读为 `D=q*(K_now-K_checkpoint)`，正数表示应付，净权益至少要扣除这项义务，即 `E=现金+未实现盈亏-D`；负数应收是否全额计入权益，须按明确的可收回性规则折扣。提款、减仓或转出等改变风险资格的操作，要与读取当前指数、结算旧仓或锁定足额保证金使用同一序列，并在提交前复核版本。若总览式周期快照已封存而账务尚未应用，风险还要读冻结计划中的应付额。链上若 `K` 更新过期，不能拿陈旧值放行提现；应先更新到受信水位或暂停相关资金外流。否则用户可在费用入账前提走抵押品，把系统留下无担保应收。

## 第 6 层：固定点精度和跨账户守恒怎样兼顾？

**面试官：** `K` 和用户现金都需要整数精度。多账户分次结算时，怎样避免舍入误差破坏资金守恒？

**面试者：** `K`、数量和乘数都用带版本的固定点整数表示，乘法用足够宽的有符号中间值，完成单位缩放后才舍入。反复推进检查点会把一笔长区间切成多段；若每段都独立截断，结果可能不同于一次性结算，因此连续累积模型要保留账户级高精度余数，或明确规定切分和余数归属，清仓时也处理余数；这不同于总览不跨周期累计资金费小数尾数的快照基线。更重要的是，不同用户在不同时间惰性结算时，用户现金流水的阶段性合计不必为零：尚未结转的付款与收款净额必须由显式资金费清算账户或应收／应付科目承接，并按指数水位核对。它是未结转义务，不是舍入尾差。只有金额量化后真实产生的离散残差才进入舍入账户；不能把全部暂态资金差塞进尾差。对同一指数增量，若全市场净仓 `Σq=0`，完整结转后的理论 `ΣD=0`；实际分录须让用户、清算账户及舍入项最终闭合，且逐户可复算。

## 第 7 层：迁到链上后，谁有权改指数和仓位？

**面试官：** 若把累计指数结算搬到合约，状态归属、调用权限和原子范围要怎样重新定义？

**面试者：** 必须先说明哪些状态真正迁链。若合约权威持有仓位，就由合约保存市场 `K`、账户检查点、仓位与已结算金额；受限的费率发布者更新有效指数，交易入口在改仓前结算旧仓，并在一次合约调用中原子更新现金、检查点、仓位和防重身份。发布者、keeper、暂停和升级权限都要约束，不能让旧权限或任意账户提交过期更新。应用指数时要检查单调序号、规则版本和最大允许陈旧度；停更时明确阻断新风险或资金外流。EVM 同一交易内状态变化及同链代币调用可一起回滚，但跨链桥和异步提款不天然原子。若仓位仍由链下账本权威拥有，链上只能验证或执行授权承诺；单独转 USDC 不会证明仓位、指数、检查点或义务正确。

## 第 8 层：确认、重组和重放后何时算经济完成？

**面试官：** 交易上链并返回成功就能宣布资金费足额收齐吗？怎样处理重组和链下核对？

**面试者：** 不能。合约执行成功只说明该笔交易在当前执行结果中通过，不保证应收金额足额、欠款已收回，也不等于跨链资产可用或经济义务最终关闭。每次指数周期或账户效果要有稳定身份、单调序号与载荷摘要；合约拒绝重复序号和同身份异载荷，链下消费者按交易哈希、事件序号及区块哈希去重。只有确认实际到账与应收差额相符，才可把对应应收结清；不足额到账仍保留欠款或未结义务。链重组时，被回滚的事件不能留在权威账本里；索引器需按目标链的最终性规则回滚投影并重放规范链事件，不能给所有链套一个通用确认块数。链下账本仍须将仓位版本、指数水位、欠款、实际代币到账及链上事件逐笔对账，差异走追加调整。否则即使链上转账不可逆，也可能只是转错人或少收款。

**收束与反例：** 核心是同单位指数差乘旧仓位、仓位变化前先结算并推进检查点；最易错的是把周期跳变的惰性实现说成连续持有计费，或把链上成功说成足额清偿。反例取 `M=2,000`、8 小时费率 `0.0001`、1 ETH 仅持有前两小时后平仓：连续按小时规则应付 `0.05 USDC`，总览快照若平仓发生在屏障前应付 `0`。若实现给两种规则算出同一结果，就没有真正区分规则或仓位时序。
