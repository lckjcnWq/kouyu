# 衍生品与风险系统：大白话导读任务清单

## 目标与范围

面向懂一些后端开发、但尚不熟悉保证金、逐仓、全仓等交易业务的读者，为本目录下全部 **64 个现有 Markdown 文件（59 篇正文 + 5 篇专题 README）** 添加前置导读。本文是执行清单，不属于待添加导读的业务文章。

每个文件在原有一级标题之后、原正文之前增加：

1. **先看懂：关键词大白话解释**：用表格解释本文的交易名词、英文缩写、公式符号及关键工程概念，说明在本文中的具体含义。
2. **把整篇文章压缩成一个故事**：沿一个具体人物或系统事件串起起因、处理过程、结果和不能理解错的边界。

## 编写与验收标准

- 保留原有标题、正文、链接、公式和问答，不借导读改变原文规则。
- 各篇导读独立可读，不用“同上”代替解释；词表按本文内容选择，不机械复制通用名词。
- 先解释真实业务，再解释后端如何保证业务成立，使用“专门的钱包、占住额度、记正式流水”等通俗说法时说明边界。
- 区分余额、权益、初始保证金、维持保证金、可用额度与可提现额。
- 不把杠杆当作盈亏二次乘数，不把逐仓当作无条件损失上限，不把全仓说成全平台互保。
- 区分标记价与实际成交价、强平触发与执行结果、超时未知与确定失败。
- 保留各篇的产品适用范围；教学数字、资金费支付方向、阈值、档位、舍入和执行策略不泛化为所有平台规则。
- 用结构检查验证 64 个文件均有且只有一套前置导读；与修改前快照比较，确认原文完整保留。
- 检查 Markdown 表格、相对链接和故事中的关键算式，更新清单及复利记录。不创建 Go 工程，不声称运行生产故障或性能测试。
