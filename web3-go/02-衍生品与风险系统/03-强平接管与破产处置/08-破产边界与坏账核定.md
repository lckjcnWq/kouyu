# 大问题 8：强平价、破产价格与最终坏账缺口怎样区分？

## 先看懂：关键词大白话解释

| 关键词 | 大白话解释 | 在本文里怎么理解 |
| --- | --- | --- |
| 保证金、逐仓现金 C | 为一个指定风险单元承担亏损的资金。 | 初始 C=20 USDC；逐仓限定核算及动用范围，不承诺亏损绝对封顶。 |
| q、P₀、线性多头 | q 是仓位数量，P₀ 是入场价；线性多头按价格差计算盈亏。 | 本例 q=1 ETH、P₀=100，不把公式泛化到反向合约或多资产账户。 |
| Mark、M | 用于判断风险的标记价。 | 不是实际卖出价格，也不是定损时可随意替代成交的报价。 |
| U、E | U 是未实现盈亏；E 是现金加浮动盈亏后的权益。 | 本例 U=q×(M−P₀)，E=C+U。 |
| MM、r、MMR | MM 是继续持仓的最低要求，r 或 MMR 是对应维持保证金率。 | 本例取 5%，MM=q×M×r。 |
| E<MM、严格边界 | 权益严格低于维持要求才进入强平复核。 | 数学等值不触发，触发也不等于已经成交或亏光。 |
| 临界触发价 | 在指定公式下，权益与维持要求恰好相等的价格边界。 | 本例为 80/0.95；只有 M 严格小于它才触发，不能用显示近似值改规则。 |
| P_bank、破产价格 | 特定假设下权益恰好归零的理论价格。 | 忽略费用时为 P₀−C/q=80，不是约 84.21 的触发边界，更不是承诺成交价。 |
| 定点精度、舍入 | 按约定最小单位计算，并明确多余小数如何处理。 | 有限位显示不能当作精确阈值，代码不能把严格小于偷偷改成小于等于。 |
| 实际成交、已实现损益 | 真正平仓后确定的成交价格和价差赚赔。 | 独立全平 1 ETH@78 时毛损益为 -22，不能叠加此前的半仓教学路径。 |
| 现金缺口、穿仓 | 在声明风险范围内，履行相关确定义务后资金仍不够的部分。 | 不能只读当前余额；费用、资金费、迟到成交等未齐时不是最终坏账。 |
| 部分平仓、未闭合敞口 | 只平掉部分数量，剩余仓位仍受后续市场影响。 | 余仓浮亏不是已经核定的最终现金欠账。 |
| 临时估值、最终定损 | 前者允许事实尚不完整，后者要求金额与依据已核齐。 | 可暂报缺口 2，但费用未定时必须注明待核定，不能宣告最终完成。 |
| 手续费、资金费、结算义务 | 成交及持仓规则带来的额外资金收付责任。 | 主例忽略这些；若同一单元另付 0.1 手续费，缺口变为 2.1，是改变假设后的变体。 |
| 逐币核算、抵押边界 | 分币种核对余额和负债，并明确可使用哪些资金。 | 核定服务不能擅自从其他逐仓或钱包挪钱补洞。 |
| loss_id、核定证据 | 稳定损失身份，以及支持金额的成交、费用、结转和规则记录。 | 同一经济损失不能因重复触发就生成两份负债。 |
| 追加调整、负余额截零 | 前者保留历史后另记修正；后者只是把显示负数改成零。 | 修正须可追溯，截零既不是偿付，也不消除责任。 |
| 保险基金、剩余缺口 | 基金按规则用有限资金承担部分损失；未覆盖的仍需处理。 | 本文独立假设缺口 2、覆盖 1.5、剩余 0.5，不是通用瀑布。 |
| ADL、配对敞口 | ADL 是按规则选择对手仓位自动减仓；需要仍有可配对的未闭合对象。 | 已全平且配对闭合的现金缺口不能凭空靠 ADL 抹掉。 |
| 补资、损失分摊、结案 | 按协议另行安排资金或损失责任，并证明安排已完成。 | 定损完成不等于清偿完成，更不允许无规则地扣其他用户资金。 |

## 把整篇文章压缩成一个故事

小林拿 20 USDC 保证金持有入场价 100 的 1 ETH 多头。权益是现金加浮动盈亏，维持保证金则是继续持仓的最低要求。本例权益低于维持要求才触发复核：临界边界为 80/0.95，严格等值不触发。Mark 到 84 时已经需要处置，但权益仍有 4，不是已经亏光，也没有保证按这个价格成交。

忽略费用时，权益恰好归零的理论破产价是 80。另走一条独立全平路径，若市场最终以 78 成交，实际亏损 22，初始现金 20 就留下 2 USDC 缺口；这条路径不叠加前文半仓成交。若同一单元还须付 0.1 手续费，缺口就变为 2.1，所以账面暂时显示 -2 并不自动等于最终定损。

系统要等余单、成交、费用和资金费等义务核齐，逐币记录损失身份及证据。不能截零隐藏负债，也不能擅自动用其他逐仓资金。即使基金按例只承担 1.5，剩余责任仍须保留；仓位及配对已经闭合时，不能凭空发起 ADL 消掉现金欠账。定损与清偿，是两个不同终点。

[返回专题总览](README.md)

**流程位置与核心机制：** 本题从风险触发、理论权益耗尽一直推到真实成交和最终缺口核定，区分三个常被混为一谈的价格／金额，并明确何时才有足够事实定损。保险基金、Backstop 和 ADL 的具体协议分配不在本题内；尤其不能把已平仓后的现金缺口说成可由没有剩余配对仓位的 ADL 凭空消失。

**必要前提：** 使用专题基线：链下托管线性 USDC 永续，单一逐仓多头 `q=1 ETH、P₀=100、C=20 USDC、MMR=5%`，忽略手续费、资金费和其他现金变化。`U=q×(M−P₀)`，`E=C+U`，`MM=q×M×5%`；严格 `E<MM` 才触发，`E=MM` 不触发。简化恢复门槛 `E>=MM` 且余单和在途义务核清，生产缓冲是显式变体。

## 第 1 层：强平触发边界在主例中如何计算？

**面试官：** 主例 Mark 90 不触发、Mark 84 触发。能否从公式中推导触发对应的价格边界？

**面试者：** 将 `E=C+q(M−P₀)` 与 `MM=qMr` 代入严格条件 `E<MM`，得到 `C−qP₀+qM(1−r)<0`。因为本例 `q>0` 且 `1−r>0`，触发区间为 `M<(qP₀−C)/(q(1−r))`。代入数值是 `(100−20)/(1×0.95)=80/0.95≈84.210526315… USDC/ETH`。

该值是由所选风险公式推得的临界边界，不是成交价，也不意味着在有限位小数上可以宣称“等于触发”。由于规则严格小于，数学等值不触发；系统实现必须使用明确的定点精度、舍入和比较约定，不能把显示出来的 `84.210526` 当成精确阈值并偷偷改变边界。Mark 90 下 `E=10、MM=4.5`，Mark 84 下 `E=4、MM=4.2`，与这个区间一致。

## 第 2 层：为什么临界触发价不是破产价格？

**面试官：** 上式得出约 84.21，破产价格是不是也约等于 84.21？

**面试者：** 不是。触发边界比较权益与维持保证金；简化破产边界是权益降到零。主例解 `E=C+q(M−P₀)=0`，得到 `P_bank=P₀−C/q=100−20=80 USDC/ETH`。在触发边界附近，账户权益仍约等于维持保证金，并未耗尽；维持保证金要求使风险处置早于理论权益归零。

两个值都依赖本例假设。若把清算费用预留计入权益、改用分档维持率、增加其他抵押、使用全仓、多资产折扣或反向合约，触发式和破产价都要重新推导。不能把公式中的一个价格标签复制到另一种保证金模型，也不能把触发后市场发生的实际滑点塞进“强平价”这个含混字段里。

## 第 3 层：执行价格低于破产边界时，缺口怎么推算？

**面试官：** 初始仓位全平，实际成交价为 78，忽略费用时风险单元发生了什么？

**面试者：** 这是一个独立全平变体，不叠加前面 `0.5 ETH@84` 的部分成交。已实现损益为 `1×(78−100)=-22 USDC`，因此初始现金 20 结转后为 `20−22=-2 USDC`，按本教学风险单元边界，现金缺口是 2 USDC。成交价低于简化破产价 80 的部分造成权益穿零，但真正的缺口必须从实际结转结果推导，而不是按 Mark 84 或临界触发价估算。

如果价格是 82，全平后现金为 2，不存在该模型下的负现金缺口，即使仓位曾经触发强平；如果价格是 78，负现金是已实现经济结果。以上都忽略费用、资金费和其他调整。真实系统还要按币种记录执行价格、成交数量、损益、手续费及适用抵押边界，避免将估值损失和已经结算的现金负债混为一谈。

## 第 4 层：为什么一次部分成交后还不能核定最终坏账？

**面试官：** 主例在 84 平了 0.5 ETH，现金是 12，剩余仓位仍有未实现亏损。此时能否按未实现亏损直接登记坏账？

**面试者：** 不能。部分成交只是把已平的那一部分损益实现，剩余 0.5 ETH 仍有市场敞口，未实现盈亏会随 Mark 和最终成交价变化。该时点按 Mark 84 计算，剩余未实现亏损 -8、权益 4、维持保证金 2.1；它说明剩余仓位的风险状态，不等于已确定的最终现金缺口。

只有仓位关闭，并且所有已确定成交、手续费、资金费、结算费用和其他相关义务都已核清，才能基于最终逐币现金计算缺口。若仍有余单或在途成交，即使当前持仓投影显示为零，也要确认不会再有迟到成交或费用变更。最终定损可使用 `loss_id` 固化证据和规则版本；后续确有调整时，应追加独立调整记录，不覆盖旧定损。

## 第 5 层：费用与结算义务怎样进入最终缺口？

**面试官：** 初步成交现金为负 2，但执行手续费还未知，能否先报缺口 2，再等手续费来了另说？

**面试者：** 可以记录临时估值或待核定金额，但必须明确不是最终缺口。如果手续费为账户应付项，它会进一步降低风险单元现金；费用未确定时应保留未结费用义务和定损待完成状态，不能以主例忽略费用的假设冒充生产结论。每项调整要带币种、金额、来源身份、业务日期和规则版本，逐项进入风险单元或协议定义的承担账户。

在当前教学计算里，独立全平 `1 ETH@78` 且费用为零时，现金 `-2`、缺口 `2`。如果费用为 0.1 USDC 且由同一逐仓账户承担，最终现金会是 `-2.1`，缺口为 2.1；这是改变了“忽略费用”的假设后得到的变体。不能只用数量×价差估损而遗漏已发生费用，也不能重复应用迟到的同一费用事件。

## 第 6 层：坏账核定时，如何处理负余额、逐仓隔离与重复应用？

**面试官：** 账户现金变成 -2，系统能不能把余额显示截成 0，再从其他逐仓仓位或全账户余额补齐？

**面试者：** 不能默默截零或跨风险单元自动兜底。负余额是需要显式承担和处置的负债；逐仓隔离边界意味着是否能动用其他逐仓、钱包余额或保险资源必须由产品协议明确，不能由核定服务自行挪用。没有明文授权时，应将 `asset=USDC、assessed_amount=2` 作为待处理缺口记录，并限制将其误报为已偿付。

缺口核定要有稳定 `loss_id`，并绑定已关闭仓位、成交及费用明细、现金结余、资产、核定规则版本和计算证据。重复触发核定或重放事件必须返回同一缺口记录，不得再次生成 2 USDC 负债；重复分配也不能多扣基金。若后续发现漏记费用，追加关联调整或更正流程并留存审计轨迹，不直接覆盖原始凭证。

## 第 7 层：保险基金与 ADL 能否自动消除这个最终缺口？

**面试官：** 假设独立教学例中保险基金先覆盖 1.5 USDC，剩余 0.5。能否认为剩余必然由 ADL 扣掉并结案？

**面试者：** 不能。保险 1.5 和剩余 0.5 只是这个例子的独立分配假设，不是通用瀑布规则；基金是否先用、覆盖上限、可用余额和币种都由协议规定。每一笔基金覆盖应以 `loss_id` 幂等记账，覆盖后剩余缺口仍然是 0.5，而不是因为某个处理流程结束就自动归零。

更重要的是，如果仓位已经全部平掉，系统中不存在该仓位对应的剩余配对敞口，ADL 不能凭空创造一个对手方仓位来抹掉现金缺口。要继续处置，只能有协议明确的补资、损失分摊、社会化损失或其他负债承接安排，并给出其账户影响和授权依据。ADL 需要协议定义仍未闭合的风险敞口及可执行的对手方安排；它不是任意负余额的通用删除按钮。

## 第 8 层：从成交到最终定损，什么证据足以结案？

**面试官：** 如何判断坏账已经核定，而不是只在数据库中生成了一条负数记录？

**面试者：** 我会要求先证明仓位已关闭且无有效余单、在途动作和未结转成交；再核对所有成交 fill、账户经济腿、已实现损益、费用和资金费已进入同一风险单元的最终现金。缺口按币种计算，原始现金与损益分录可追溯，规则版本明确，并且 `loss_id` 唯一，避免同一经济损失重复核定。

定损完成与缺口清偿还要分开。若核定缺口 2、基金按协议覆盖 1.5，尚余 0.5，那么缺口金额已经可以核定，但处置责任未必结清；必须保留待补资或协议损失分摊状态。只有协议承担记录、资金转移或相应负债安排完成并可对账，才可称损失处置结案。案例页面、账户余额截零或没有告警，都不能代替这些证据。

## 本题收束

- **机制：** 由严格 `E<MM` 推导触发边界约 `80/0.95≈84.210526`，由 `E=0` 得简化破产价 80；以真实成交和全部费用／义务核定最终逐币现金缺口，使用稳定 `loss_id` 防重。
- **易错边界：** 临界触发价不是破产价格，也不是成交价；严格等值不触发，有限小数显示不等于精确阈值；部分仓位和未结费用未清前不能报最终缺口；负余额不可截零或越过逐仓边界自动兜底。
- **反例：** 全平后现金为 -2，保险假设覆盖 1.5，系统把剩余 0.5 记给 ADL，但此时没有任何剩余配对仓位或对手方安排。这个记账没有可执行经济对象，不能消灭缺口；必须另有协议规定的补资或损失分摊机制，并保留责任直到完成。
