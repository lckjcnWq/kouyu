# 大问题 2：AMM 怎样确定成交数量，为什么不能用池余额比例计算所有报价？

## 先看懂：关键词大白话解释

| 关键词 | 大白话解释 | 在本文中的含义与边界 |
|---|---|---|
| AMM / 边际价格 | 用曲线兑换的池子，以及此刻极小交易对应的价格 | 不靠订单簿撮合，也不自动读取外部价格重设成交条件 |
| x、y、k / xy=k | 两种储备及其乘积构成的兑换约束 | v2对照中x为T0实储备、y为T1实储备；手续费留池后实储备乘积会增长 |
| g、f、a、b | 毛输入、费率、净输入和输出 | T1输入时a=g(1-f)，v2输出b=xa/(y+a)；不能按起点价格直接换完整笔 |
| P / s | T1计价的T0价格，以及它的平方根 | P=T1/T0=s²；T1买T0时s上升，反向交换须换公式和符号 |
| 活跃L | 当前价格段真正参与兑换的曲线深度 | 只在不跨边界的单段固定，不能把A/B的L全程相加 |
| 虚拟储备x_v、y_v | 把局部曲线写成恒定乘积的数学坐标 | x_v=L/s、y_v=Ls，乘积为L²，不是可直接转出的实际池余额 |
| s_a、s_b / 本金偏移 | 头寸下上界的平方根价格，以及有限区间扣除的常量 | 区间内本金x=L(1/s-1/s_b)、y=L(s-s_a)，本金不含另记的手续费 |
| s' / 单段delta | 本段结束的平方根价格，以及本段币量变化 | 上行净入L(s'-s) T1、输出L(1/s-1/s') T0；跨界后换新L再算 |
| 平均支付价 / 最终现价 | 整笔付出除以收获，以及成交后池的局部价格 | 1500/输出为含费平均价，1495.5/输出为净额口径，均不等于最终s² |
| 套利 / 外部参考价 | 利用不同市场价差交易，以及池外的比较价格 | 套利可能推动池价靠近外部价，不保证一致，更不证明现价可安全用于清算 |

## 把整篇文章压缩成一个故事

工程师阿成给小林算1500 T1能买多少T0，最初想用池余额比例。这里两币均18位精度、输入费0.3%、协议不分成，P按T1/T0计。全区间v2对照池若x=y=100000，净输入1495.5，沿曲线只得约1473.464341 T0，而非1495.5。回到正文的有限区间池，A的虚拟储备虽各为100000，实际本金却远少于此，B还在区间外持有T0，余额比例根本不是现价。阿成改为读取同版本sqrt价格、活跃L与边界：先用A到tick240，再换B的L50000处理余量，连续模型总输出约1472.669192，真实金额仍按合约整数舍入核对。含费平均支付价约1.01856，最终现价约1.03599，两者不能混称滑点。他又检查区间外增资不改变起点价、下一段深度改变只影响跨界交易。曲线算对只说明规则执行正确，外部公平价、清算安全和LP保本都不是这条公式的承诺。阿成还按币种分别核对输入、输出与费用，不把两种币数量裸加；反向时则重写符号和公式，明确哪种币是输入。比较时必须保持配置一致，不拿资金规模不同的对照池推断主例收益。

[返回专题总览](README.md)

**流程位置与核心机制：**从执行前状态推导单段输入、输出和边际价格；区分全区间恒定乘积与集中流动性的虚拟储备。本题建立数学依据，整数实现见03，多个区间的执行循环见05。

**必要前提：**主例仍为总览的 v3 风格 T1 输入。第2层临时改用全区间 v2 模型做数学对照；离开该对照后恢复 A/B 的原始区间与资金条件。

## 第 1 层：一个 AMM 没有订单簿，怎么知道给用户多少 T0？

**面试官：**用户输入 1500 T1，AMM 不能与对手挂单撮合，依据什么确定输出？

**面试者：**AMM 把当前状态与定价规则当作成交约束，由交易改变状态并沿曲线移动。它不是先读一个外部价格，再按固定比例兑换整个数量。价格通常是曲线当前点的边际兑换率，大额成交要沿曲线积分，因此平均成交价不同于初始报价。

本专题采用集中流动性，定价所需的是当前 sqrt 价格、活跃 L、方向、输入费和经过的 tick 边界。只在 L 不变的区间内，才可以用一组单段公式计算。1500 T1 足够跨过 A 上界，必须先算 A 段，再按 B 的 L 算余量。

所以完整回答不能停在“自动做市用 x乘y等于k”；还要说明 x、y 是实际储备还是虚拟储备，公式在哪一段成立，费用怎样处理，以及跨界后如何变更参数。

## 第 2 层：先用最简单的恒定乘积说明为什么余额比例不够

**面试官：**你说边际价不能乘整个数量。先改变前提，用没有集中区间的 v2 型池推导一次给我看。

**面试者：**设实际储备为 x 个 T0、y 个 T1，忽略其他转账，以 `xy=k` 定价。输入 T1 毛额 g，费率 f，计入定价的净额 `a=g(1-f)`。扣费曲线要求 `(x-b)(y+a)=xy`，因此输出 `b=xa/(y+a)`，而不是 `a/(y/x)`。

例如明确改用 `x=y=100000` 的全区间对照池，g 为1500、f为0.003，a为1495.5，输出约1473.464341 T0。起点价格是1，但沿曲线买入使价格上升，所以不能给1495.5 T0。

如果手续费留在池中，实际交易后 T1 储备增加的是 g，不是 a，故实储备乘积会增长。用净额推导的等式是定价关系，不能据此断言含费交易后的实际储备乘积仍严格等于原k。该对照池的资金规模不是主例两笔有限区间本金，不能据输出相近就说两种配置等效。

## 第 3 层：回到集中流动性，x乘y等于k完全失效了吗？

**面试官：**恒定乘积能推导 v2。回到 A 的有限区间，v3 是换了一条完全无关的曲线吗？

**面试者：**不是。固定活跃 L 的局部段可写为虚拟储备 `x_v=L/s`、`y_v=Ls`，仍有 `x_v y_v=L²`，边际价格 `y_v/x_v=s²=P`。

但有限区间头寸的真实本金要扣除与边界有关的偏移。单个头寸在区间内有 `x=L(1/s-1/s_b)`、`y=L(s-s_a)`，因此 `x_v=x+L/s_b`、`y_v=y+Ls_a`。真正成立的是带偏移的局部关系，不是实际本金直接相乘等于 L²。

本例 A 在 s=1 时，真实 T0/T1 本金分别约1192.769433，而虚拟储备各为100000。B 还在区间外持有约589.271222 T0。拿全池实际余额比价，初始 T1/T0 约为 `1192.769433/1782.040656`，明显不等于池的真实边际价1，这就是不能用余额比例替代 slot0 价格的具体反例。

## 第 4 层：从虚拟储备怎样推出单段输出？

**面试官：**既然虚拟储备决定曲线，请推导 T1 输入使 sqrt 价格上升时的金额公式。

**面试者：**固定 L 时，虚拟 T1 储备是 Ls，因此 s 从原值移动到更大的 s'，净输入为 `a=L(s'-s)`。虚拟 T0 储备从 L/s 下降到 L/s'，输出为 `b=L(1/s-1/s')`。

如果已知净输入 a，先算 `s'=s+a/L`，再算 b。反向 T0 输入时，价格向下，净输入是 `L(1/s'-1/s)`，T1 输出是 `L(s-s')`，符号和方向不能照抄上行公式。

输入手续费不是令价格直接跳一个百分比。连续模型先将毛输入扣费得到净输入，净输入推动曲线，费用另记给活跃 LP；真实实现还要考虑每步舍入。这样才能同时回答价格变到哪里、用户收到多少、LP赚哪一种币。

## 第 5 层：这组公式能否直接算完主例1500？

**面试官：**你已经有 s' 等于 s 加 a除以L，为什么不拿1495.5直接除以100000，算完整笔？

**面试者：**因为那会越过 A 的上界，超出了 L100000 不变的适用范围。先算到 tick240 的净输入门槛 `100000(s_b-1)≈1207.168166 T1`；1495.5大于该门槛，必须切段。

第一段输出约1192.769433 T0，用掉约1210.800568 T1毛输入。跨界后 A退出、B进入，L变为50000。剩余净输入约288.331834，令最终 `s'=s_b+288.331834/50000≈1.017838318337`，第二段输出约279.899759 T0。

因此总输出约1472.669192。若把整笔都按L100000算，实际上是假造 A 在上界以外仍提供流动性，会高估剩余深度。单段公式正确但使用区间错误，端到端报价仍然错误。

## 第 6 层：初始价格、平均价、最终价格究竟怎么区分？

**面试官：**按你的分段结果，用户到底是以1、1.01856还是1.03599成交？

**面试者：**三个值分别描述不同对象。起点边际价格是1 T1/T0，表示交易前无穷小兑换对应的局部斜率。成交后边际价格是 `s_final²≈1.035994842274`，用于描述交易后状态。用户整笔含费平均支付价格是 `1500/1472.669192≈1.018558687872 T1/T0`。

如果讨论纯曲线价格影响，还应剥离输入费，使用 `1495.5/1472.669192≈1.015503011808` 作为净输入平均支付价，并说明这是何种口径；不能把最终边际价上涨约3.60%直接说成整笔用户滑点3.60%。报价后的外部状态变化属于另一种不确定性，和交易自己沿曲线造成的影响也要区分。

多段深度不同，使大额交易的平均价与最终价之间没有固定差值。面试时先声明以T1/T0支付价还是T0/T1输出价衡量，再谈百分比，否则两种倒数口径会把损失比例讲混。

## 第 7 层：外部市价不同，AMM公式怎么保证合理价格？

**面试官：**你的曲线只看池状态。如果外部市场突然变了，池会自动知道新价格吗？

**面试者：**不会。这个模型没有在每笔兑换前读取外部价格并重设池状态。外部价格变化会创造套利机会，套利交易者沿池曲线兑换，将价格推向外部市场附近；实际偏离受手续费、gas、资金、竞争和流动性约束影响，不保证随时一致。

LP在这个过程中向交易者卖出相对上涨的资产、买入相对下跌的资产，头寸构成随曲线被动变化。曲线约束保证的是合约规定的兑换规则，不是LP保本，也不是价格抗操纵。

因此报价服务不能把“计算完全符合曲线”当作“此价格可作为清算预言机”的证明。执行报价、历史TWAP、外部参考价有不同用途；若用户依赖外部公平价，需要另外定义价格偏离保护，而不是偷偷修改池的数学结果。

## 第 8 层：怎样验证不是只背出了公式？

**面试官：**公式和套利都能背。给你一个错误报价实现，你会用什么性质找出它的问题？

**面试者：**我先检验方向与守恒：T1输入应提高P，T0输出不得凭空增加；每个币种分开核对变化。再检查区间：每一步的终点不越过下一边界，跨界前后的L按net变化，手续费归旧L。

然后用可手推的反例区分实现。保持同一slot0和活跃L，只给区间外B增加T0本金，起点边际价不应按全池余额比例改变；减少下一段L则应影响跨界大额报价，却不影响尚未跨界的小额段。这能同时揭穿“余额比价”和“整笔固定L”两类错误。

最后把实数推导与目标合约整数规则分开：连续公式用于解释和数量级核对，精确输出要与固定版本算法逐步对照。这里提出验证方法，不声称已经运行了合约差分测试或证明所有边界正确。

## 本题收束

- **讲透的机制：**恒定乘积定价怎样从状态推出数量，集中流动性怎样用虚拟储备保留局部曲线，又怎样被tick边界切成多段。
- **最容易答错：**真实余额等于虚拟储备、含费实储备乘积严格不变、最终边际价等于整笔平均价、固定L公式可以跨任意区间。
- **反例检验：**主例起点池实际本金T1/T0约为0.669，而slot0价格是1。任何根据这组实际余额给出起点价格0.669的v3报价器，都已使用错误状态定义。
