# 大问题 8：集中流动性 LP 赚了手续费，为什么仍可能跑输持币不动？

## 先看懂：关键词大白话解释

| 关键词 | 大白话解释 | 在本文中的含义与边界 |
|---|---|---|
| LP / 固定区间 | 提供兑换本金的人，以及只在一段价格上生效的头寸 | 本文比较A的[-240,240)、L100000，不追加资金、不自动复投 |
| HODL / x0、y0 | 把最初同样数量的两种币原封不动持有 | 基准各持约1192.769433 T0/T1，不能换成全仓T0或另一份投入 |
| P、s、a、b | T1计价的T0价格、其平方根及区间上下界sqrt价格 | P=s²=T1/T0，有限区间本金随s分段计算，L不是资产总值 |
| V_LP / V_HODL | 同一时点用T1衡量的本金价值 | 分别按xP+y与x0P+y0算；必须同终点价格，基础无常损失不含手续费 |
| 无常损失 / 相对损失 | LP本金相对原币不动少了多少 | 本例本金差约-28.534815 T1、相对约-1.17501%；不是币凭空丢失或必然会恢复 |
| 绝对收益 | 终点资产相对初始价值增加多少 | A含费且未扣gas绝对增加约18.031135 T1，仍可同时跑输HODL |
| 输入费 / 区间费用归属 | 付入币种的费用，只分给当步活跃LP | 本例0.3%费、协议不分成；4.5 T1中A仅得约3.632402，不得独占B那段 |
| 出界 / 调仓 | 原头寸暂不参与成交，以及退出旧范围重建 | A高于上界全T1且停赚该区间外交易费；主动换币重建会改变路径并产生费用、冲击和gas |
| collect / tokensOwed | 把已记欠款领走，以及含本金或费用的待领账 | 领取只挪资产位置，不能再造收益；退出本金不能被误当成手续费 |
| APR / LVR / MEV | 年化指标、另一种相对基准的损失指标及交易排序影响 | 历史APR非承诺，LVR与无常损失不可不辨基准直接叠加，MEV也可能抬高调仓成本 |
| blockHash / 估值来源 | 资产读取版本，以及用于换算价值的价格 | 同版本去重核算资产；可操纵现价的账面价值不等于真实退出可得，重组需撤回旧投影 |

## 把整篇文章压缩成一个故事

阿敏问：“A明明赚手续费，为什么报表还说跑输了？”分析师先固定两币18位、T1/T0计价、输入费0.3%、协议不分成，且不追加资金、不复投。她最初各投入约1192.769433 T0/T1。1500 T1买T0把池推到tick353，A出界后本金只剩约2399.937600 T1；若原币不动，在相同终点价约值2428.472415 T1，本金相差约28.534815。A只能加自己那段约3.632402 T1费用，含费后虽比初始多约18.031135，仍落后持币约24.902413，且尚未扣gas。后端按同一块哈希核对本金、应计费用、待领和已领取资产，collect只移动位置，不重复记收益，实数小数不冒充链上精确结果。阿敏若调仓，须把换币冲击和成本纳入新路径；不调仓等价格回来也没有未来保证。最终报表区分绝对收益与相对表现，拒绝把窄区间、高历史APR或频繁波动包装成保本承诺，也不把可操纵现价当成必能兑现的退出价。出界之后的成交费不再属于她，历史费用也不会自动加成新流动性；相同终点可以有不同费用路径。若以后追加或提取资金，比较账户也必须匹配资金流，不能继续沿用这次无增资的简单差额。

**流程位置与核心机制：** 沿“初始投入→交易改变库存→费用归属→退出估值”比较收益，不提供收益承诺。公共基线与单位见总览；本题以 A 的固定区间为例，使用 T1 计价，与相同初始两币数量的 HODL 比较，不追加资金、不自动复投。

```text
记录初始两币数量与估值时点 → 价格变化使 LP 库存沿曲线转换
    → 分别统计剩余本金、已赚费用、已领取资产
    → 用同一终点价格给 LP 与相同初始资产 HODL 估值
    → 扣除 gas、调仓及其他实际成本 → 判断绝对盈亏与相对表现
若退出交易失败 → 不算已退出；重组则撤回相应资产与收益投影
```

主例用户最多付 1500 T1 买 T0，最低输出 1470 T0，上限 tick420、deadline 路由检查。交换跨 tick240 后，最终 s≈1.017838318336633561、P≈1.035994842274346199、tick353，活跃 L=50000。本文用连续实数手算，不把结果称为链上实测；整数执行有逐步舍入。

## 第 1 层：说 LP“亏了”，究竟和谁比较？

**面试官：** A 收到了手续费，账户用 T1 计价也涨了，为什么你还说它可能亏？

**面试者：** 必须区分绝对盈亏和相对持币损失。绝对盈亏比较终点净资产与初始资产价值；无常损失通常把 LP 不含费用的本金，与“原来同样数量的 T0、T1 一直不动”在终点的价值比较。两者基准不同，可以同时出现绝对赚钱、相对跑输。

我先固定 T1 为计价币、同一终点价格、相同初始资产和外部资金流；不能拿 LP 的双币投入去对比全仓 T0，也不能把 LP 的费用和 HODL 的本金混在不同时间价格下比较。领取费用只是资产从池内转到钱包，不会凭空创造第二份收益。T1 计价上涨也不代表法币购买力一定上涨，本题暂不加入外部汇率。

## 第 2 层：相同初始资产怎样从有限区间推出来？

**面试官：** 你要求相同初始资产，那 A 的投入是多少，能不能直接套全域 AMM 的无常损失公式？

**面试者：** 不能直接套。令 a=1.0001^-120，b=1.0001^120，A 初始 s0=1，投入为 `x0=L(1/s0-1/b)` 和 `y0=L(s0-a)`，恰好各约 1192.769433438381804424。初始总值约 2385.538866876763608848 T1，HODL 就固定持有这两个数量。

对当前 s，有限区间的本金为：s≤a 时全 T0，x=L(1/a-1/b)；a<s<b 时 x=L(1/s-1/b)、y=L(s-a)；s≥b 时全 T1，y=L(b-a)。其 T1 价值是 xP+y，HODL 则是 x0P+y0。集中区间、初始配比和出界截断都会改变比较结果，因此不能把全域 v2 的 `2√r/(1+r)-1` 当成所有 v3 头寸的通用答案。

## 第 3 层：把主例的相对损失真正算出来？

**面试官：** 你给了分段公式，那最终 tick353 时 A 的本金和 HODL 分别值多少？

**面试者：** 最终价格高于 A 的上界 tick240，A 已全部换成 T1，不再持有 T0 本金。它的本金为 `L(b-a)≈2399.937599775025698687 T1`。同样的初始资产一直持有，则在 P_final≈1.035994842274346199 时价值为：

`V_HODL=1192.769433438381804424×P_final+1192.769433438381804424≈2428.472414503039439281 T1`。

所以不含手续费的差额约为 -28.534814728013740594 T1，相对 HODL 约 -1.175010865%。这不是 token 从合约里失踪，而是价格上涨过程中 LP 持续卖出 T0、累积 T1，终点持有的上涨资产少于 HODL。数值核对必须先确认比较的是本金，不能把 feeGrowth 或已领取余额不加区分地塞入公式。

## 第 4 层：加上手续费，不就补回来了吗？

**面试官：** A 的本金少了 28.5348，但整笔交换收了 4.5 T1 手续费，你是否漏算收入？

**面试者：** 要加费用，但不能把全池费用全给 A。价格走到 tick240 前，A 承接净入 1207.168166336643894263 T1、毛入 1210.800568040766192842 T1，赚取约 3.632401704122298579 T1。后续净入 288.331833663356105737 T1，由 B 承接并赚约 0.867598295877701421 T1；这部分不属于 A。

A 含费价值约 2403.570001479147997266 T1，仍比 HODL 少 24.902413023891442015 T1，尚未扣 gas。但它又比初始价值多约 18.031134602384388417 T1，所以绝对收益为正、相对表现为负同时成立。若仅靠费用填平主例的本金差额，A 需要约 28.5348 T1 的累计费用，而不是只要出现手续费收入就算胜出。

## 第 5 层：出界后等着，损失会不会自己恢复？

**面试官：** A 已经全是 T1，继续放着是否还能赚费，或者价格一回来损失就自然消失？

**面试者：** 区间外头寸仍存在，但不参与当时价格处的成交，因此不赚那段交换费。若价格继续上涨，A 本金维持 T1 数量不变，而 HODL 里的 T0 继续升值，相对差距可能扩大。若在不调仓、不增减资的理想模型下，价格回到初始位置，本金配比会沿曲线恢复，先前的相对本金损失可回到零；这不是对真实未来价格的保证。

如果 LP 在高位退出旧区间并换入 T0 建新仓，就改变了后续基准和路径，不能再声称旧头寸“等回来就恢复”。重新入区间通常要换币，会遇到成交冲击、手续费、gas 和三明治风险。调仓有实际资本成本，不能把每次区间重置后的短期正收益拼起来，抹掉前一段已经实现的相对损失。

## 第 6 层：同样起点终点，LP 收益是否一定相同？

**面试官：** 你强调价格回来的路径，那如果起点终点一致，两次 LP 的总收益还会不同吗？

**面试者：** 对同一个固定区间、同一个 L，忽略费用和资金变动，本金由终点价格决定；但手续费取决于中间发生多少交换、哪些时段头寸活跃，以及当时有多少其他 L 分摊。价格来回震荡可能多次过区间，也可能大部分交易发生在区间外，不能只看终点算费用。

还要区分成交量与可分得费用：同样的交易量，竞争 L 翻倍，单位 L 的收入可能下降；窄区间提高活跃时的资本利用率，却缩短活跃范围并提高管理压力。费用默认作为可领取欠款单独记账，不会自动变成新增 L；假设自动复投时，应显式记录再次加仓的数量与成本。单段利润不能外推成年化保证，也不能说“波动越大，LP 一定越赚”。

## 第 7 层：后端怎样计算不自欺的净收益？

**面试官：** 路径、复投、领取都会改变余额，你如何做一个不会重复记账的收益报表？

**面试者：** 我会记录初始注资、后续增减资、已领取本金与费用、调仓兑换及 gas，并按同一 blockHash 对应的估值时点给未退出本金、待领余额和已转出资产估值。collect 只移动资产位置，不能既把它算收入，又继续把同一余额计在池内。tokensOwed 可能包含退出本金，不是纯手续费字段。

本例从未追加资金，才能直接比较终值；存在追加或提取时，应建立匹配资金流的 HODL 账户，或明确使用时间加权、资金加权中的哪一种口径。gas 若用原生币支付，需要选定换算时点，而非直接忽略。收益价格最好用与用途匹配、独立可核对的来源；若用一个可被短时操纵的池现价估算自己的退出价值，账面利润和真正能成交的利润可能完全不同。

## 第 8 层：报表正确，就能按高 APR 决定投入吗？

**面试官：** 已经扣完成本、统一估值，能否只选择历史手续费 APR 最高的区间？

**面试者：** 仍然不能。历史手续费不是未来交易量承诺，区间竞争、价格趋势和出界时间都会变。还要评估合约与授权风险、token 信用或脱锚风险、退出深度、MEV，以及管理策略的失效条件。标准 token 假设只排除了转账税和 rebase，不排除这些风险。

我会把“价格不变却几乎无交易”“突破上界继续单边上涨”“跨界震荡且其他 L 大量进入”分别推演，核对收益来自哪里、损失由谁承担。若使用无常损失、套利损失或 LVR 等指标，必须说明各自基准，不能把重叠经济损失机械重复相加。没有真实数据就给机制分析和敏感条件，不编造回测胜率、实测年化或最优区间。

## 收束：讲透机制、易错边界、反例验证

- **讲透机制：** 集中 LP 是随价格变化的库存策略；本金比较用相同初始资产 HODL，费用与成本另计，有限区间必须分段估值。
- **易错边界：** 正的绝对收益不代表跑赢持币；费用不会自动复投；出界仍有头寸，但不代表仍在赚费。
- **反例验证：** 主例 A 含费绝对赚约 18.0311 T1，却相对 HODL 少约 24.9024 T1。若系统把两者都显示为“净赚 18.0311、无损失”，它混淆了基准，而非证明 LP 没有风险。
